### 【开源自荐】LLMxRay：本地大模型观测台，测量提示词缓存的复用 👤 LogneBudo
> LLMxRay 是一个连接本机 Ollama 的大模型观测台，完全在本地运行：不需要 API key，不需要注册，不向外部发送任何数据。 提供逐 token 的流式诊断、模型并排对比、基于 logprobs 的基准测试、嵌入与 RAG 检索，以及一个把同一提示词分别发往 Ollama 原生、OpenAI 兼容和 Anthropic 兼容三个接口的协议对比页。 最新的 v0.6.0 加了一个「缓存实验室」：本地模型只有在提示词从第一个 token 起完全一致时才会复用 KV 缓存，所以系统提示词顶部的一个时间戳，会让整段提示词每轮都重新计算。实测同一个 324 token 的提示词，时间戳放在开头时缓存只复用 4 个 token、预填充耗时 64.6 ms；放到结尾则复用 290 个、耗时 18.6 ms —— 文字完全相同，预填充快了 3.5 倍。这个页面会标出缓存断裂的位置，并在你自己的守护进程上实测改写后能省多少，不做任何估算。 界面和 README 有完整中文版。Apache-2.0 协议。 一条命令启动：npx llmxray

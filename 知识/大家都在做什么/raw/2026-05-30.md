### 【开源自荐】TerAgent：一个编译器风格的AI Agent中间件 👤 Kiruvex
> AI Agent 是 2026 年的技术热点之一。当前的 Agent 框架普遍存在两个问题：一是每换一个模型就要重写一套 Prompt，二是安全机制往往后置。 TerAgent 是我发布的一个开源库，核心定位是为 AI Agent 提供类似编译器的中间层。用一句话概括：用户只需要定义一个 5 字段的数据结构（TAPRequest），剩下的 Compiler 负责把它转成模型需要的 Prompt 格式，Adapter 负责发 HTTP 请求并收响应。 一、TAP IR TAP 全称 TerAgent Protocol，定位是内存中的中间表示（IR），类似 LLVM IR。它只包含 5 个字段：meta（元信息）、context（上下文）、instruction（核心指令）、constraints（硬约束）、outputformathint（输出提示）。描述的是“你想让 AI 做什么”，但不关心“怎么组织成 Prompt”。 TAPRequest → Compiler → CompiledPrompt → Adapter → Model API，中间经过编译和发送两层解耦。 二、Compiler / Adapter 正交解耦 这是项目的核心设计。Compiler 管编译策略（例如 GLM 近因效应 / Claude XML / DeepSeek 极简），Adapter 管 HTTP 协议（OpenAI 兼容 / Anthropic 原生 / Mock）。 4 个 Compiler 乘 3 个 Adapter，一共 12 种组合，零额外代码。新增一个 Compiler 只需要加一个文件一行注册，Adapter 同理。这个扩展能力在有多模型需求的场景下很实用。 三、安全与可靠性模块 AI 在幻觉状态下可能执行危险操作（例如说清理日志却执行了 rm rf）。TerAgent 内置了多个防御机制： 7 层权限解析：用户级规则优先级最高（100），系统级最低，同优先级下默认拒绝优先于允许。 3 级沙箱隔离：依次为进程级（黑名单 + rlimit）、Docker 容器、Firecracker 微型 VM。 2PC 原子文件写入：先验证写后读契约，再写临时文件，最后原子替换，失败则自动回滚并备份。 4 种熔断器：Token 预算监控、连续失败冷却、延迟滚动告警、进度停滞检测。 GLM5.1 在独立评估中称其“本质是一个防 AI 自毁系统”。 四、开发方式 TerAgent 的设计是与 AI 协作完成的，代码不是手写的。整体流程是：设计（我与 AI 讨论）→ 规划（AI 拆解任务）→ 编码（AI 逐模块生成）→ 审查（AI 进行语法/依赖/可运行性检查），我在每一关做决策。 GLM5.1 对项目做了独立评估，给出综合评分 7.4/10（架构设计 9.0，防幻觉安全 7.5，工程规范 6.5）。评估报告存在仓库的 docs 目录下。 五、技术指标 源码约 22,207 行 Python（14 个子模块，83 个源文件） 测试约 15,071 行（44 个测试文件），测试/源码比 67.9% 0% 空壳（714 个函数全部实现） 版本 0.0.1 Alpha，许可证 Apache 2.0 六、相关链接 GitHub: PyPI: pip install teragent 开发者（GitHub）: @Kiruvex

> 项目名称 Vibe Coding Guide 项目地址 GitHub: Website: 一句话介绍 一份中英文双语的 AI Coding / Vibe Coding 实战指南，目标是把“随手 prompt 让 AI 写代码”变成可审查、可回滚、可复用的工程工作流。 推荐理由 很多开发者已经在使用 Codex、Claude Code、Cursor、Aider 等 AI Coding 工具，但真正困难的不是让 AI 生成代码，而是： 如何写清楚 spec，让 Agent 知道边界； 如何维护 AGENTS.md / CLAUDE.md，把项目知识长期沉淀下来； 如何管理上下文窗口、压缩、交接和重启； 如何使用 subagent、workflow、worktree 做并行协作； 如何用 diff review、测试和 CI 管住 Agent 写出来的代码； 如何识别常见反模式，避免 AI Coding 变成不可维护的“爽感编程”。 这个项目不是 prompt 大全，而是面向真实工程场景的工作流指南。 项目亮点 中英文双语：README、完整教程和 PDF 都有中文/英文版本； 有 GitHub Pages 网站版，包含 16 天费曼学习清单； 覆盖 Spec、Context、Agent Plan、Diff Review、Tests/CI、Commit、Docs/Handoff 的完整循环； 适合正在使用 Codex、Claude Code、Cursor、Aider 等工具的开发者； 内容以 Markdown / PDF / Website 形式公开，适合收藏、阅读和二次学习。 适合人群 已经开始用 AI 写代码，但觉得产出不稳定的开发者； 想把 AI Agent 纳入真实开发流程的工程师； 想学习 subagent、worktree、skill、CI guardrails 等 AI Coding 工程实践的人。

### 【开源自荐】别人还在讨论 Karpathy 的 LLM Wiki，我已经拿它造了个会进化的 AI 分身 👤 justlovemaki
> 阮老师好，自荐一个自己做的开源项目。 Hex2077Agent —— 一个"三位一体"的 AI 数字分身系统，将人格、知识库和多端通讯深度融合。TypeScript + Fastify，Docker 一键部署，GPL3.0。 做这个项目的起因是，现有的 AI 聊天方案要么是无状态的对话（聊完就忘），要么是 RAG 检索（每次查询从零开始拼凑知识）。我想要的是一个真正"越用越聪明"的数字分身——它有自己的知识体系、一致的表达风格，还能出现在我活跃的所有平台上。 知识层：LLM Wiki 知识复利 这部分深度实践了 Karpathy 前两天发的 LLM Wiki 构想。上传文档后不是简单建索引，而是： 自动语义拆分 → 提取实体（Entities）和概念（Concepts）→ 生成互联的百科页面 新知识与旧知识智能合并（去重 + 冲突处理），不是堆积，是"认知升级" 人格层：多Agent 动态调度 不是一个大 System Prompt 搞定一切，而是多个 Agent 协作：Strategist 分析意图 → Knowledge Expert 检索知识 → Persona Keeper 守护人格一致性 → Style Enforcer 风格重塑 → Identity Shaper 最终整合。效果是分身的回答在逻辑和语感上高度统一，不会出现"AI 味"忽浓忽淡的问题。 渠道层：全平台一个大脑 集成了 OpenClaw China，支持微信（个人号/公众号）、飞书、钉钉、企业微信、QQ。所有渠道共享同一个知识库和人格。同时提供 OpenAI 兼容的 /v1/chat/completions 接口，可以对接任意第三方客户端， 还支持iframe接入网页。 其他 一键人格重构：输入一段描述（如"活泼的二次元少女"），自动重写全部 11 个 Prompt 模块 SSE 流式响应，Web 端实时展示各 Agent 执行状态 已发布 Docker 镜像，dockercompose up d 即可启动 项目地址： 项目试用 AI日报 ， 右下角的按钮点击后，在对话框可试试效果 个人项目，欢迎提 Issue 和 PR。感谢阮老师的时间。

### 【开源自荐】Horizon：让 LLM 帮你过滤与总结新闻 👤 Thysrael
> 项目名称：Horizon 项目地址： 项目 Demo： 项目简介： Horizon 可以从多个可自定义的多个信息源（RSS，HackerNews，Telegram Channel，Reddit）收集新闻，给新闻打分并过滤，最终生成一份新闻日报。 Horizon 会将高分新闻挑选出来，并且生成详细的摘要。不仅如此，Horizon 还会收集社区意见（来自新闻源的评论区）并且为新闻中的新概念提供解释（网络搜索避免幻觉），并提供中英文版本的日报。降低了阅读了解时事的门槛。 此外，Horizon 可以作为一个 cron job（或者 Github Action），生成一个日报静态网站，方便每天的查看。 项目截图： 日报目录： 新闻摘要： 推荐理由： 降低了信息搜集的难度：对于开发者来说，及时了解科技新闻是一个非常重要的需求。但是不同的新闻往往遍布在不同的网站上，搜集起来很花精力。RSS 可以部分解决这个问题，但是 RSS 订阅一旦增多，就会导致噪声很大。因此 Horizon 在此基础上提供了 AI 打分过滤功能。 优化新闻阅读体验：在读新闻的时候，有些背景知识我们并不清楚，在读完以后，我们也希望获得一些其他人对于这个新闻的看法（即新闻评论）。Horizon 针对这些需求，提供了翻译、总结、搜集新闻评论，补充背景知识的功能。 可定制性强：本体是一个 python cli 工具，生成的日报是一份 markdown 文件，所以非常容易以多种形式部署（demo 就是部署在 github page 上了）。用户也可以自定义信息源，Horizon 不仅支持 RSS，还支持许多其他类型的信息源的订阅。 希望分享给周刊的读者们，帮助大家在新闻爆炸的时代尽可能从容一些 :)

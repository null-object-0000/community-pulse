### 【开源自荐】1Nuo-Rating-System：为静态博客打造的量化评测工具 👤 1nuoiscute
> 项目名称：1NuoRatingSystem 项目地址： 项目简介： 专为静态博客（Hexo/Hugo 等）设计的轻量级量化评测管理工具。通过可视化后台直接驱动 GitHub API 更新仓库中的 JSON 数据，实现零服务器成本的云端同步。内置加权评分引擎与 ECharts 可视化看板，让感性的评价逻辑化，让数据管理轻量化。 项目截图： <p align="center" width="48%" / width="48%" / </p 推荐理由： 解决痛点：静态博客在维护结构化评价数据（如 JSON 数据库）时，手动编辑源码效率低且易出错。本项目通过 GUI 表单代替代码编辑，并支持 File System Access API 直接读写本地文件，实现了“数据输入”与“代码维护”的彻底解耦。 严谨量化模型：内置四维度加权评分引擎，目前已应用于山西古建筑等景点评测中，评价维度涵盖：建筑视觉、文化共鸣、游览体验、质价比。支持自定义权重公式： $$Final\ Score = \sum (Scorei \times Weighti) + Bonus{tags}$$ 零成本 Serverless 架构：巧妙利用 GitHub API 充当云端数据库。博主无需购买或维护任何服务器，即可在网页端完成数据的增删改查，非常适合追求极致轻量化的静态博客用户。 数据可视化交互：集成 ECharts 动态生成全球/全品类评分分布图，并提供“项目对撞机（PK Mode）”功能，支持在同一坐标系下对不同目标进行直观的数据博弈。 跨界开发者实践：项目作者并非计算机专业出身，在 AI 协作下完成了从山西古建实地考察需求到完整工具链的开发闭环。这是一个非常典型且有趣的“技术赋能个人生活”的开源案例。 希望分享给周刊的读者们，特别是那些热爱量化生活、正在寻找轻量级 CMS 方案的博主们。 :)

### 【开源自荐】AgentCut -- 多 Agent 协作的 AI 视频生产工具，一条 Prompt 生成完整视频 👤 calderbuild
> 项目名称：AgentCut 项目地址： 成品演示： （一条 Prompt 自动生成，带旁白、背景音乐、字幕，17 秒完整成片） 项目简介： AgentCut 是一个多 Agent 协作的 AI 视频生产工具。输入一段文字描述，6 个 AI Agent 按照标准化流程（SOP）协作，自动完成从创意策划到成片剪辑的全过程，输出一个完整的 MP4 视频。 架构流程： 用户输入 Prompt | v [Director Agent] 分析创意方向，规划分镜 | v [Script Agent] 编写详细制作脚本（视频提示词、旁白、字幕） | +++ | | | v v v [Visual Agent] [Voice Agent] [Music Agent] 视频生成(Hailuo) 语音合成(TTS) 背景音乐生成 | | | +++ | v [Editor Agent] ffmpeg 合成：拼接视频、混音、烧录字幕 | v 最终 MP4 Visual、Voice、Music 三个 Agent 并行执行，Editor 等三者全部完成后合成最终视频。 生成成本： | 环节 | 费用 | ||| | LLM 调用 (Director + Script) | ~$0.01 | | 视频生成 (3 个镜头) | ~$0.300.60 | | 语音合成 (3 段旁白) | ~$0.01 | | 背景音乐生成 | ~$0.05 | | 合计 | ~$0.400.70 / 视频 | 技术栈： | 组件 | 技术 | ||| | LLM | MiniMax M1 (Director + Script) | | 视频生成 | MiniMax Hailuo 2.3 (1080P, 6s) | | 语音合成 | MiniMax Speech2.6HD (带情感 TTS) | | 背景音乐 | MiniMax Music2.0 (纯音乐) | | 视频合成 | ffmpeg (拼接、混音、字幕) | | 后端 | Python FastAPI + SSE 实时推送 | | 前端 | HTML + Tailwind CSS | 项目截图： <p align="center" width="80%" / </p <p align="center" width="80%" / </p 推荐理由： 1. 完整的多 Agent 协作架构：不是简单的 API 调用封装，而是 6 个 Agent 各司其职、流水线式协作，体现了 Agent SOP（标准作业流程）的设计思路。 2. 真实可用：一条 prompt 到一个完整 MP4，端到端跑通。每个视频生成成本约 $0.400.70。 3. 实时可视化：前端通过 SSE 实时展示每个 Agent 的工作状态和日志，整个生产过程透明可见。 4. 轻量部署：支持 Docker 一键部署，也可以 pip install 后直接运行。 5. 开源 MIT 协议，代码简洁，适合学习多 Agent 编排模式。

### 【工具自荐】NanoMaker：一次订阅，使用多种主流 AI 模型 👤 crayon-nickee
> 大家好，分享一个自己做的 AI 工具平台： NanoMaker 的核心思路很简单：只需一次订阅，可以使用多个主流 AI 模型。 目前支持： 1、图像生成（支持Nano banana 和pro） 2、视频生成（支持sora 2和veo3.1） 3、AI 音乐生成（支持suno） 4、语音与音频处理（支持elevenlabs） 不同领域的模型统一在一个界面和账户体系中，避免分别订阅多个平台，可以大幅减少成本，适合内容创作者，以及希望系统体验不同 AI 模型的人。 项目还在持续迭代中，欢迎大家提出改进建议。

### 【项目自荐】ego lite：一个你和 AI Agent 共用的浏览器 👤 Davidyooo
> ego lite 是一个基于 Chromium 的浏览器，可以给人日常使用，也可以给 AI Agent 操作网页。 项目地址： 官网： GitHub： 我们做它，是因为现在很多 Agent 任务最后都会卡到浏览器里：调研资料、操作 SaaS 后台、读登录后的页面、填表、抓取没有 API 的网站数据。网页还是现实世界里最常见的“接口”。 但现有的浏览器自动化方案，用起来经常有几个问题： 临时开的自动化浏览器没有真实登录状态，遇到 SSO、2FA、验证码就很麻烦； 直接桥接 Chrome，又容易把用户正在用的窗口和标签页弄乱； 很多工具把浏览器操作拆成一条条命令，Agent 要反复“点一下、看一下、再点一下”，慢，也浪费 token； 复杂网页里的 iframe、shadow DOM、第三方组件，普通页面抓取经常拿不到完整结构。 ego lite 的思路是：把浏览器本身改造成一个人和 Agent 都能使用的工作空间。 几个主要特点： 1. 人和 Agent 各有自己的 Space 你可以把 ego lite 当普通浏览器用。Agent 执行任务时，会在自己的隔离 Space 里打开页面，不会抢你的标签页，也不会打断你正在浏览的内容。你可以随时切过去看它在做什么，必要时接管或停止。 2. 复用真实浏览器环境 ego lite 可以迁移 Chrome 的书签、扩展、Cookie 和登录状态。Agent 操作网页时，不必每次从一个空白 Chromium 重新登录，处理内部系统、SaaS 后台、GitHub、Google Docs 这类页面会顺很多。 3. 不是让 Agent 一条条敲命令，而是让它写 JS 配套的 egobrowser 会把 snapshot、click、fill、navigate、capture 等浏览器能力暴露成 JavaScript 函数。Agent 可以把一个多步网页任务写成一段 JS 一次执行，而不是不断调用 CLI 工具、等待输出、再继续下一步。 4. 更适合文本模型读取网页 我们在 Chromium 内核里做了语义 Snapshot，让文本模型能更稳定地“看到”页面结构，包括一些普通 JS 抓取容易漏掉的 iframe、shadow DOM、React Portal、Stripe / Salesforce / Intercom 这类第三方组件。 一个典型用法是，在 Codex 或 Claude Code 里直接让 Agent 做网页任务，例如： bash egobrowser 打开 GitHub，整理这个仓库最近 20 个 issue 的类型

### 【开源自荐】RepoReaper：基于 DeepSeek 和 AST 的“类人”代码审计 Agent 👤 tzzp1224
> 项目名称：RepoReaper 项目地址： 项目简介： 一个试图解决 RAG "切片破碎"痛点的 AI Agent。 传统的 RAG 只是机械地把代码切成文本片段，导致函数逻辑断裂。这个工具模仿了高级工程师的认知流程： 全局认知：先扫描目录树，建立架构地图。 AST 切分：利用 Python 抽象语法树，按类(Class)和方法(Method)的边界完整切分代码，保留逻辑完整性。 ReAct 补全：阅读中发现缺失的引用，会自动触发 GitHub API 下载依赖文件 (JIT)。 可视化：直接输出 Mermaid 架构图和时序图。 基于 DeepSeek V3 构建，支持 Docker 一键部署，适合用来快速阅读陌生的开源项目源码。

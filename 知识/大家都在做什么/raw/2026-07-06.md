### [开源自荐] OxiDNS：面向复杂网络的 Rust DNS 策略编排引擎 👤 svenshi
> 项目地址 类别 Rust 项目标题 面向复杂网络的 Rust DNS 策略编排引擎 项目描述 OxiDNS 是一个使用 Rust 编写的 DNS 策略编排引擎，适合家庭网关、旁路由、OpenWrt、NAS 和 Homelab 等复杂网络环境。它支持通过声明式配置组合匹配、缓存、转发、回退、改写、本地应答和系统联动等能力，帮助用户构建可控、可调试、可扩展的自建 DNS 基础设施。 亮点 OxiDNS 的亮点在于不是简单提供一组 DNS 开关，而是把一次 DNS 查询拆成可组合的策略管线。用户可以根据域名、客户端 IP、查询类型、响应 IP、返回码等条件选择不同处理流程，并结合多上游并发、主备回退、缓存、TTL 调整、ECS 处理、ipset/nftset/RouterOS 地址列表同步等能力，构建比较精细的 DNS 策略。 相比偏开箱即用的家庭 DNS 工具，OxiDNS 更强调可组合、可调试和可演进。它内置查询记录、实时日志、Prometheus 指标、配置校验和热重载能力，方便用户理解一次查询为什么这样处理。对于 Rust、网络编程、DNS 协议、异步系统、插件化架构和配置驱动设计感兴趣的开发者，也可以把它作为一个完整的基础设施工程项目来学习。 示例代码 markdown 截图或演示视频 执行链路查看 <img width="1210" height="519" alt="Image" src=" / 插件依赖拓扑图 <img width="1596" height="658" alt="Image" src=" / 仪表盘 <img width="1920" height="911" alt="Image" src=" /

GitHub 下载和 Git 依赖经常超时 MirrorProxy 不仅能代理 GitHub Release、Raw 文件和源码压缩包，还支持 Git Smart HTTP Clone。 独立客户端可以自动配置 GitHub HTTPS URL 重写： mirrorproxy set github baseurl 之后使用： 的 Git Clone 和包管理器 Git 依赖，会自动改走

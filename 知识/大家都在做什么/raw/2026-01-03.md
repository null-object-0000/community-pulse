### 【工具自荐】CV DebugMate C++: 一款适合计算机视觉/SLAM C++开发者的 1D/2D/3D数据可视化VS Code 调试插件 👤 dull-bird
> 项目名称 CV DebugMate C++ 项目地址 一句话介绍 一款为 VS Code 补齐“视觉”短板的 C++ 调试可视化扩展，让计算机视觉与算法调试告别枯燥的内存数值。 详细介绍 在进行计算机视觉或机器人相关开发时，VS Code 开发者常因无法直观查看内存中的数据而陷入“盲调”。CV DebugMate C++ 灵感来源于 Visual Studio 著名的 Image Watch 插件，旨在打破 C++ 调试器与图形化展示之间的隔阂。它无需开发者在代码中临时插入任何绘图指令（如 cv::imshow），即可在断点停下的瞬间，将复杂的内存变量自动转化为直观的 1D 曲线、2D 图像或 3D 点云。 核心特点 多维全能可视化 (MultiDimensional Support)： 业内领先的同时支持 1D 数值序列（曲线/直方图）、2D 图像（OpenCV Mat/矩阵）及 3D 点云（Three.js 渲染）的 C++ 调试扩展。 零配置自动检测 (AutoDetection)： 深度集成 VS Code 调试协议，自动扫描当前作用域内的可视化类型，无需手动输入变量名，实现“即停即看”。 极高性能的交互体验 (HighPerformance Interaction)： 支持 100 倍像素级缩放观察、多视图同步联动（Sync View）、按轴着色渲染等，完美处理高分辨率图像与海量点云数据。 广泛的调试器兼容性 (Broad Compatibility)： 完美适配 GDB、LLDB 及 MSVC，无论是 Windows 上的 MSVC 还是 macOS/Linux 环境均可无缝使用。 非侵入式调试 (NonIntrusive)： 纯 Webview 实现，不污染用户源代码，单步调试时自动刷新视图，极大提升算法复现与 Bug 定位效率。 技术栈 VS Code Extension API, TypeScript, Webview (HTML5/CSS3), Three.js (3D Rendering). 适用场景 非常适合从事 Open CV 图像处理、自动驾驶感知算法、机器人运动控制及计算几何的开发者。它是从 Visual Studio 迁移至 VS Code 的 C++ 算法工程师必备的效率利器。

> 项目名称：LeetSolv 项目地址： 简介： LeetSolv 是一个本地运行的 CLI 工具，用「间隔重复」的方式管理算法 / LeetCode 题目的复习。 我在 2025 年中前后做了约 190 道 LeetCode，发现一个问题：题目一直在往前做，但旧的解题思路会慢慢遗忘。只靠收藏题目或笔记，很难形成稳定的复习节奏。 LeetSolv 的思路不是背解法，而是定期重新做题。它会根据题目的重要性、熟悉度和思考深度，计算复习优先级，帮助决定「今天应该复习哪些题」。 特点： • 计分强调推理，而不是闪卡记忆 • 针对到期题目计算复习优先顺序 • 零依赖、本地运行

### 【工具自荐】ISO 8583 银行卡报文解析器，纯浏览器本地运行，不注册不上传 👤 lizhi5753186
> 项目地址： 背景 我做银行卡支付系统，日常有一大块时间是盯着 ISO 8583 的原始报文看。这是 1987 年的协议，现在绝大多数刷卡授权还跑在它上面。一笔交易被拒了，手上只有一串十六进制，要么拿着字段表一个字节一个字节数，要么随便找个在线解析器贴进去。 后者的问题是那些站基本都要注册，而且你没办法知道它拿你的报文干了什么。而报文里是有卡号和磁道数据的。 所以自己写了一个：贴进去，逐域拆开，不注册，解析全在浏览器本地跑。 在线报文解析 MTI（版本 / 类别 / 功能 / 来源）、主次位图、128 个数据域按 ISO 8583:1987 字典逐域解析，支持 LLVAR / LLLVAR 变长前缀 DE 55 按 BERTLV 递归解析，带 EMV 标签名 肉眼读不了的那几个位串字段单独做了解码器：TVR（tag 95）、AIP、TSI、CID、ATC、IAD、CVM List、CVM Results 支持 ASCII / Hex(BCD) / EBCDIC 三种编码，可选卡号脱敏 width="750" Mastercard IPM 清算文件解析（T112） 这块是我自己最想要的功能。在线报文的解析器网上还找得到几个，清算文件的基本没有。1014 字节分块、VBS 记录框、EBCDIC 解码都自动处理，PDS 子域直接展开，字段视图和 JSON 两种输出。 它必须在本地跑，是因为 IPM 文件从来不是测试数据，里面每一条都是真实卡号和真实交易。那些要你把清算文件上传上去的工具，多数发卡行和处理商在合规上根本不允许用。这个页面没有上传接口，断网也能跑。 width="750" 码表速查 DE 39 / DE 3 / DE 22 / MTI / MCC / 150 种货币 / EMV 标签 / AID，码表和对应的解码器互相链接，不用在表和报文之间来回跳。 中英双语。 关于数据 解析是纯前端 JavaScript，报文和文件本身都不发往任何地方，network 面板里能自己验证。页面上有 Google 广告和统计。 说明 站上工具全部免费。另外有一个 39 美元的离线版，是同样这些工具打包成互不依赖的单个 HTML 文件，给规定「真实卡号不许碰网站」的团队用。只用测试数据的话，免费版就是同一个工具。

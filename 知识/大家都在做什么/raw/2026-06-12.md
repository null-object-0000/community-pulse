### 【开源推荐】MovableType：像活字印刷一样搭表单，配置驱动的 React 表单引擎 👤 zakihuang
> 1. 项目地址 GitHub: 2. 它解决了什么问题？ 前端表单开发是业务系统中最重复、最琐碎的工作。每新增一个表单，都要手写 JSX、校验规则、联动逻辑，改一个字段往往要动多个文件。更麻烦的是，编辑页和详情页长得几乎一样，却要写两套代码。 MovableType 的核心思路是：像活字印刷一样搭表单——字段定义一次，表单配置百次复用。你只需写一份 JSON 配置，引擎自动生成带布局、校验、联动的完整表单，改需求时只改几行配置，而不是几十个组件文件。 3. 核心功能与特性 配置驱动渲染： 基于 React + Ant Design 4，将字段池（FieldDescriptor）与表单配置（Config）解耦，同一份字段定义可被 N 个表单复用。 声明式联动： 内置 watch（字段级/区块级）和 dataLoader（异步选项加载），无需手写 useEffect 和 onChange 监听。 灵活布局： 直接复用 antd 24 栅格系统，支持 1/2/3 列布局、字段级 colSpan 覆盖、自定义区块组件接管。 查看模式一键切换： mode="view" 时所有输入框自动变纯文本，编辑页和详情页共用一套配置。 组件可扩展： 支持同步渲染器和异步懒加载，自定义组件无需改引擎源码。 为 AI 而生： 极简三概念（字段池 / 配置 / 组件注册表），配置是纯结构化数据——大语言模型最擅长生成的格式。 4. 推荐理由 表单开发占据了中后台系统大量的重复劳动，市面上的表单方案要么过于重量级，要么自创一套 DSL 增加学习成本。MovableType 选择了最轻量的路径：不重新发明表单体系，只做 antd Form 的"配置翻译层"，三个核心概念覆盖绝大多数场景。更重要的是，它的配置天然适合 AI 生成——未来让 LLM 直接输出表单配置、而非手写 JSX，是完全可行的开发范式。对于有大量中后台表单需求的前端团队，这是一个值得关注的效率工具。 详细教程： 演示项目：

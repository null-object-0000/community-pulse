### 【开源自荐】Tunlease：保留 Webhook 原 URL，把指定路径临时转发到本机 👤 iml885203
> Tunlease 一个面向 Webhook 开发场景的开源反向隧道工具：保留第三方服务正在使用的 callback URL，只把其中一条指定路径的实时流量临时转发到开发者本机。 项目地址： 项目网站： 开源协议：MIT 开发 Webhook 时，ngrok、localtunnel 一类工具通常会产生一个新的公开 URL。但是在团队环境中，第三方平台的 callback URL 可能由管理员统一配置，开发者不能随时修改；多人共用 staging 入口时，也不能把整个 host 都转发到自己的电脑。 Tunlease 解决的是这个问题。 团队先将现有 callback host 路由到自行部署的 Tunlease gateway，第三方服务保存的 URL 不需要改变。开发者连接后，只有自己 claim 的 path 会通过 WebSocket 隧道到达本机，其他所有 path 仍然由原来的应用处理。 安装 CLI 后，可以使用公共测试 relay 体验： bash tul claim '/demo/mytunnel/' p 8080 g tunleaserelay.dotw.me 连接期间，该路径的请求会进入本机 8080 端口；按下 Ctrl+C 后自动释放。未被 claim 的路径仍会交给原服务处理。 !Tunlease demo 项目使用 Go 开发，提供 macOS、Linux 和 Windows 安装方式，也包含 Helm Chart，方便团队自行部署到 Kubernetes。公共 relay 不需要注册，但仅用于测试流量。

### 四百只鸭子与田埂上的歌 👤 hoxiai
> 辍学以后，我的人生是从四百只鸭子开始的。 那一年，我十四岁。 爷爷养了一大群鸭子，四百多只。灰白色的羽毛连成一片，远远看去，像是谁把一朵云扔到了田野里。 于是我成了放鸭人。 每天早上天刚亮，爷爷挑着鸭食，我扛着竹竿，一起往河边走。 鸭子，看起来傻乎乎的，其实最不好管。尤其是刚放下水的时候。栅栏门一开，四百多只鸭子瞬间炸开，像一盆水泼出去。东边几十只往稻田里钻，西边一群扑腾着往河汊子游，还有几只愣头愣脑的，站在原地发呆。 我拿着竹竿在后面追，跑得满头大汗，嗓子喊哑了。鸭子却根本不理我。 那时候我经常觉得委屈——为什么连鸭子都不听我的？ 爷爷却从来不急。他慢悠悠走过去，竹竿往水面一点，嘴里发出几声奇怪的口哨声。鸭群竟然一点点聚拢回来，像听懂了命令一样。 后来我问爷爷怎么做到的。爷爷笑了笑："鸭子刚下水的时候饿。饿的时候谁也管不住。等吃饱了就好。" 那时候我听不懂。很多年以后才明白——人其实也一样。饿的时候、穷的时候、慌的时候，谁都很难讲道理。 我最喜欢的时间是下午三四点。太阳开始往西边偏，河面上铺着一层金光。鸭子们吃饱了，嗉子鼓鼓的，三三两两漂在水面上。有的打盹，有的梳理羽毛，有的慢悠悠转圈。整个世界忽然安静下来。 我坐在河边，竹竿横在膝盖上，什么都不做，就看着它们。那种感觉很奇怪——明明什么都没有发生，可心却特别安静，像所有烦恼都被河水带走了。 那个时候的我还不知道，人生很多最难熬的时候，其实都需要这样的时刻：什么都不想，什么都不争，只是安安静静地坐一会儿，让心缓过来。 有一个画面，我看了一整年，却从来没有看腻。 鸭子找食的时候，会突然把头扎进水里，屁股朝天，两只脚蹼在水面上扑腾。过几秒钟再猛地抬起来，嘴里往往叼着一颗小螺狮，然后仰起脖子，咕咚一声吞下去。再继续下一个猛子。一个，又一个，不停重复。 我坐在岸边看，看久了，甚至会学着它们的频率——等它们钻下去，我屏住呼吸；等它们抬起头，我跟着出一口长气。我就那样坐着，守着这群只顾低头填饱肚子的家伙，一直坐到太阳偏西，也不觉得时间难熬。 还有一段时间，是冬天。 那时候田里的稻子已经收完了，风很硬，吹在脸上像刀子一样，河水也冷得发黑。鸭子反而更难管了，因为田地空了，它们可以去的地方更多。 我们这一片放鸭的，不止我们一家。村里有两户人家养鸭，所以鸭子是分片区放的，各自守各自的地界，不能越界。一越界就容易踩进别人家的田里。 收完稻子的田看起来很干净，但其实更危险。稻子割完以后，田里会留下很多禾桩，那是用镰刀割出来的断口，一根一根立在泥里。表面看只是短短的茬子，但边缘很锋利，走快一点，一不小心就会划到腿。 我那时候穿着胶鞋，鞋底厚，但鞋筒不够高。冬天下田久了，水早就渗进去，脚一直是湿的，时间长了反而麻木。 鸭子一乱跑，我就得跟着下田去拦。脚在泥里一深一浅地踩着，禾桩就在脚边一根根掠过去。 有一次，我追一群往别人田里钻的鸭子。 当时注意力全在鸭群上，没有看脚下。 田里全是禾桩，一根一根立在泥里。 我踩进去的时候，其实已经被划了很多次，但当时完全没有感觉，只是一直往前追。 脚是麻的，不知道疼，也不知道已经受伤。 直到把鸭群赶回河边，我才停下来。 停下来以后，才觉得不对。 裤腿变得很沉，鞋里也是湿的。 低头一看，两条小腿都在流血。 血不是一下子流出来的，而是一路慢慢渗出来的，混在泥水里，看不太清楚，只是一直往外扩散。 那一刻我才第一次真正明白，放鸭子这件事，不是"看着一群鸭子"那么简单。它是要用身体去换的，换秩序，换责任，换那四百只鸭子不跑散。 我还是把鸭群赶回了河边，像什么都没有发生一样。只是走路的时候，腿开始一点一点发热，隐隐作痛。 真正难熬的是晚上。 鸭子回棚以后，爷爷要守鸭棚，我得一个人回家。从鸭棚到家有六里路——一条田埂路，过后便是树林路。白天走起来不算什么，天一黑就完全变了样。两边全是庄稼，风吹过来沙沙作响，远处偶尔有狗叫。还有几座坟头孤零零蹲在田边，白天看是土包，晚上看像坐着的人。 我很害怕。真的害怕。 十四岁的男孩子，已经知道什么叫逞强了，所以我从来不说。每次都是硬着头皮往前走，脚步越来越快，最后几乎变成小跑。可恐惧这种东西，不是靠跑就能甩掉的——它始终跟在你后面，离你半步远。 后来有一天，我学会了一个办法：唱歌。 一开始只是小声哼，后来发现不管用，于是越唱越大声，唱到最后，几乎是在喊。我没有会唱的歌，全是瞎编，想到什么唱什么。有时候唱鸭子，有时候唱爷爷，有时候唱今天捡到了多少螺狮。有时候干脆反复唱："我不怕。我不怕。我不怕。" 声音在田野里飘出去很远。月亮听见过，星星听见过，路边的狗尾巴草也听见过。 唱着唱着，胆子居然真的大了。因为声音一出来，人就不再觉得自己是一个人——好像黑夜里有个同伴陪着你。那个同伴，就是自己的声音。 春天过去，夏天过去，秋天过去，冬天也过去了。 我跟着爷爷放了一年鸭子。学会了看天气，学会了赶鸭群，学会了在泥巴路上走一天不喊累，也学会了一个人面对漫长的黑夜。 这一年没有课本，没有考试，没有成绩单。可我学到的东西，一点不比学校里少——只是没人给我打分。

### 自荐软件：whatbroke — 对比 AI Agent 两次运行的行为差异 👤 arthi-arumugam-git
> 你好，自荐一个开源命令行工具。 whatbroke 用来对比 AI Agent 在两次运行之间的行为变化。换了模型、改了提示词、升级了框架之后，Agent 的回复看起来往往还是正常的，但底层行为可能已经变了：某个工具调用悄悄消失、参数发生漂移、成本和延迟上涨。文本 diff 看不出这些, , Agent 可以嘴上说"订阅已取消"，实际却没有调用 cancelsubscription。 用法：把两次运行各记录成一份 JSONL trace（提供零改动的抓取代理、Node SDK、Python 记录器三种方式，也可以导入现有的 OpenTelemetry / Langfuse / LangSmith trace），然后 whatbroke diff before.jsonl after.jsonl，它会报告消失的工具调用、参数变化、调用顺序变化、成本和延迟回归。有破坏性变化时退出码为 1，可以直接放进 CI。 仓库： MIT 协议，输出确定性，完全离线，不需要账号和 API key 安装：npm install g whatbrokecli；Python 记录器：pip install whatbrokerecorder 附带简体中文 README README 里有一段真实录制的演示：换成小 3 倍的模型后，回复依然通顺，但取消订阅的工具调用悄悄消失了。 谢谢！

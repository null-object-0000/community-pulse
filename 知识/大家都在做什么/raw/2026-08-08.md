### 【开源自荐】LeePanel 一个零残留的 Linux 服务器管理面板软件 👤 gna1280072
> 开发缘由 用面板管理服务器的朋友应该都有过这样的纠结：装宝塔、1Panel、cPanel 这类面板，确实省事，但你得在服务器上安装一整套面板程序——它以 root 权限常驻运行、还要开放一个公网端口、留下一堆配置文件和数据库。 等哪天想卸载，往往还得 SSH 上去跑卸载脚本，残留清不干净。 面板本来是来帮你管服务器的，结果它自己成了服务器上最大的"外来物"和攻击面。 最近发现了一个思路完全不同的开源项目 LeePanel，用了之后觉得值得推荐给各位。 核心思路：面板不装在服务器上 LeePanel 是一个桌面客户端（Windows / macOS / Linux 都支持），它不在服务器上安装任何东西——所有操作都通过 SSH 执行命令完成。也就是说： 零服务端代码：服务器上没有任何 LeePanel 的进程、文件 零额外端口：只用你已有的 SSH 端口，不开 8888/8080 零资源占用：面板运行在你的电脑上，服务器 CPU/内存一分不占 零残留：关掉软件就是卸载，服务器保持你配置时的原样' 传统面板的安全风险不是被"缓解"了，而是从架构上就不存在。 功能：麻雀虽小，五脏俱全 安装包只有 6 MB +左右，但功能覆盖面相当完整： SSH 终端 + SFTP 文件管理（拖拽上传下载、大文件分块传输） LNMP 一键部署：Nginx / MySQL / MariaDB / PHPFPM，版本可选，PHP 多版本切换 站点管理：虚拟主机、Let's Encrypt SSL、反向代理（支持 WebSocket）、伪静态 MySQL 数据库管理：增删改查、用户权限、备份恢复 Redis 管理：键值浏览、TTL、DB0–DB15 切换 Docker：容器/镜像生命周期管理、日志、镜像源 系统监控：CPU / 内存 / 磁盘 / 网络实时图表 防火墙规则、BBR 加速、软件源管理 多服务器管理，侧边栏一键切换 技术栈 Tauri 2.x + React 19 + TypeScript，SSH/SFTP 底层用的是 Rust 的 russh，本地数据存 SQLite。MIT 协议开源。目前对 Ubuntu / Debian 支持最完善，CentOS/RHEL 等发行版适配也在推进中。 适合谁 洁癖党：不希望面板污染服务器环境 安全敏感场景：不想为了方便多开一个公网端口 低配 VPS：不占服务器一分资源 多服务器运维：一个客户端统一管理，随时切换 链接 GitHub： 官网：

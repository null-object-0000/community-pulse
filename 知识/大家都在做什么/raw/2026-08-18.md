### 【开源自荐】PortPilot：让 localhost 服务直接给其他设备访问 👤 BeyondXinXin
> 自荐一个最近做的 Windows 开源小工具：PortPilot。 项目地址： 我最开始做它，是为了测试 Godot Web 游戏：构建后的网页文件在电脑上，希望直接用手机或另一台电脑访问，又不想每次单独搭 Web Server。 后来类似需求越来越多，比如把本机的 Ollama、ComfyUI 提供给另一台电脑使用，但原服务继续保持 localhost；或者临时通过 IPv6、Tailscale、HTTPS、公网入口访问本地服务。 所以做了 PortPilot。它的思路是：原来的服务继续保持 localhost，由 PortPilot 负责创建合适的访问入口。 主要支持： 直接发布静态网站目录，适合 Godot Web、前端构建产物等，不需要额外启动 Web Server。 代理已有 HTTP / HTTPS 服务，例如 Ollama、ComfyUI 或其他本地 Web 服务，原服务继续监听 localhost 即可。 IPv6 Direct：有公网 IPv6 时直接访问，路径短、额外依赖少。 Tailscale Direct：通过 Tailnet 直接访问本机服务。 Tailscale Serve：把本地服务发布为 Tailnet 内可访问的 HTTPS 地址。 Tailscale Funnel：需要时临时把本地服务开放到互联网。 Remote Bridge：把远程电脑上的服务桥接成当前电脑自己的 localhost，适合依赖 localhost、Host 或 Origin 的 Web 应用。 PortPilot 不替代 Tailscale，而是把 Tailscale Direct / Serve / Funnel 这些原本分散的访问方式统一到一个桌面界面里。已经安装 Tailscale 的用户，可以直接选择适合当前场景的方式；没有 Tailscale 时，也可以使用 IPv6 Direct。 Remote Bridge 来自另一个实际需求：我把 DeepSeek Harness 跑在另一台电脑上，但希望当前电脑仍然能够通过真正的 localhost 使用它，而不是直接访问远端 IP。PortPilot 可以在两台机器之间建立桥接，最后在本机得到一个正常的 localhost 地址。 多个服务可以放在一个界面中统一管理，分别启动、停止、重启，并直接复制对应的访问地址。 PortPilot 是 Windows x64 单文件程序，无需安装。配置、日志等运行数据统一保存在： text %LOCALAPPDATA%\BeyondXinXin\PortPilot\ 不会写入 EXE 所在目录。 项目地址：

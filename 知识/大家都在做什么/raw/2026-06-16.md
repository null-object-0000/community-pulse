### [[开源推荐] GitPulse：本地优先的多仓库 Git 工作报告生成器](https://github.com/GoldenZqqq/GitPulse) 👤 GoldenZqqq
> 项目地址 类别 JS（Tauri + React + Rust 桌面应用） 项目标题 本地优先的多仓库 Git 工作报告生成器 项目描述 GitPulse 是一个基于 Tauri 2 + React 19 + Rust 的本地优先 Git 工作报告生成器。它可以扫描本机多个工作区下的 Git 仓库，按作者、日期区间和分支范围提取 commit，一键生成日报、周报、自定义区间报告和绩效月报，适合需要整理工作进展、复盘项目产出或交付周报的开发者使用。最新版本支持在设置中自定义报告输出模板，日报、周报、月报和自定义区间报告都可以按自己的格式生成。 亮点 本地优先：仓库扫描、提交提取和报告生成都在本机完成，提交记录不上传服务器。 多仓库聚合：可配置多个仓库根目录，自动发现 Git 仓库，并缓存仓库索引以加快后续生成。 生成更快：报告生成会按本机并发能力有界并行提取提交，适合几十个仓库的日常工作区。 过程可见：仓库扫描支持进度展示和取消；生成报告时显示已处理仓库数、并发数和提交数。 报告直接可用：支持日报、周报、自定义区间报告和绩效月报，可复制预览内容，也可导出 Markdown、Word 或 PDF。 报告格式可自定义：v0.3.6 新增报告模板设置，可分别配置日报、周报、月报和自定义报告的输出结构，并提供变量校验与样例预览。 证据可追溯：可在报告中保留仓库、分支、日期、commit hash 和原始提交信息，便于复核。 提取更准确：支持全部分支归因，并可过滤 merge、revert 和 bot 提交。 可选 AI 润色：支持 OpenAI Compatible、Anthropic Native 和 ChatGPT Codex OAuth；失败时自动回退本地模板。 安全存储：API Key 和登录态保存在系统凭据库，不写入普通配置文件。 设置诊断：内置一键诊断，可检查 Git、工作区、仓库索引、Git 作者、输出目录、AI 凭据、PDF 中文字体、GitHub 网络和更新清单。 更新更方便：Windows 支持应用内更新，并提供 gitpulselatest.json 更新清单；macOS / Linux 可从 Releases 手动下载安装包。 跨平台桌面端：提供 Windows、macOS、Linux 安装包，另有中英文官网页面方便查看介绍和下载。 示例代码 bash git clone cd GitPulse npm install npm run tauri dev 截图或演示视频 !GitPulse 操作流程演示 官网： 高清 MP4： Release 下载：

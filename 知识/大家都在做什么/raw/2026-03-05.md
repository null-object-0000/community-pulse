### 【开源自荐】PC Agent — 让你的电脑变成 AI Agent 系统可感知的「外挂」 👤 MaskerPRC
> 我平时用 n8n 搞了很多自动化流程，但有个一直很头疼的问题：n8n 跑在服务器上，没法直接操作我的电脑。 比如我想实现这些场景： 剪贴板一复制，自动翻译/存档 电脑解锁了，自动发条消息到手机 在 n8n 里点一下，电脑弹个提醒框 远程让电脑念一段话（TTS） 这些都需要一个「桥梁」装在电脑上，把 PC 的事件推出去，同时能接收外部指令。 所以我写了 PC Agent。它是一个 Electron 桌面应用，干两件事： 往外推：监听 7 种系统事件（剪贴板、窗口切换、开关机、锁屏、USB 插拔、网络变化、空闲状态），有变化就 POST 到你指定的地址。 往里收：本地跑一个 HTTP 服务（127.0.0.1:18677），支持弹通知、弹窗、写剪贴板、打开文件、截图、文字转语音。应用会轮询你的 n8n webhook 拿指令，所以不用开端口，也不用内网穿透。 还顺手做了个 Chrome 扩展，n8n 可以通过它控制浏览器——打开标签页、执行脚本、获取页面内容之类的。 UI 用的是黑白新粗野主义风格（NeoBrutalist），就是那种粗边框、硬阴影、等宽字体，看起来有点「毛坯房」但挺带感的。 技术栈：Electron + Vue 3 + Express + SQLite + TypeScript。自带交互式 API 文档页面，打开就能测试所有接口。 说白了就是给自动化玩家准备的 PC 端「遥控器」，配合 n8n / Dify / 任何能发 HTTP 请求的平台都能用。

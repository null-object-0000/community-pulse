### [开源推荐] greencheck：用变异测试查你的质量门禁是不是摆设 👤 simin-yuan
> 很多项目 CI 一路全绿，不是因为代码没问题，而是那条检查规则从来没真正生效过。greencheck 会在你的配置和代码里自动制造小改动：删掉一行、把数值改成 0、清空一个字段，然后看你的门禁还拦不拦得住。拦不住的地方，就是它根本没在管的地方。纯 Python 标准库实现，零第三方依赖，装完直接用，不用改你现有的门禁配置。 亮点 1. 审计的对象是「门禁本身」而不是被检查的代码。同类工具大多在查代码，查检查规则的很少。 2. 零依赖、pip install 完就能跑，也可以直接 python -m greencheck.cli 调用，不侵入现有 CI。 3. 示例自带、可复现：仓库里的 demo 会当场跑出一个逃逸的变异——把 "replicas": 3 改成 0（一个永远起不来的服务），而门禁只说「键都在、值都非空」，所以放行。结构上的每条规则都还成立，这正是这类缺口能活下来的原因。 4. 不夸大：输出明确写着「这些是值得你去想的问题，不是结论」，不会拿变异数冒充缺陷数。 5. 同一个思路还能用来审计指标：一个永远等于 1.0 的自评分，不是测量出来的，是装饰。

### 开源了一个透明桌面计划软件 DeskPlan：拖入文件安排任务，工作时不挡窗口 👤 blp205769
> 分享一下自己的桌面计划软件 **DeskPlan （日序）**，MIT 开源，支持 Windows 、macOS 和 Linux ，中英文界面。 想解决的是一个很小的需求：计划留在桌面上，能随时看到下一件事，但不要盖住正在工作的窗口，也不想为了记录待办先注册账号。 [产品主页与 15 秒真实应用演示]( https://asoming.github.io/deskplan/zh-CN/#demo) · [GitHub 源码]( https://github.com/asoming/deskplan) · [下载安装包]( https://github.com/asoming/deskplan/releases/latest) ![DeskPlan 日序真实界面，使用示例任务]( https://asoming.github.io/deskplan/assets/planner-zh-CN.png) 目前可以这样用： - **文件直接变成计划**：拖入文件、文件夹或 `.code-workspace` 创建任务，也可以关联到已有任务。只记录路径，不移动或上传原文件。 - **四档处理优先级**：马上做、尽快做、按计划做、先放着，颜色不同。尽快做的任务距截止时间不超过 48 小时，会自动显示在马上做。这里是四档优先级，不是重要性 × 紧急性的双轴矩阵。 - **今天与本周**：今天挑出最重要的三件事；本周可以拖动安排日期、填写预计耗时。计划日期和截止日期分开。 - **安静留在桌面**：背景和文字透明度独立可调；窗口位于桌面之上、普通应用之下。侧栏鼠标停留才出现，也能缩成小窗；托盘常驻，不占任务栏。 - **本地优先**：无需账号，任务可离线使用；有子清单、重复任务、可选提醒、备份和导出。启用更新检查或下载时会连接 GitHub ，安装重启由自己选择。 例如，可以拖入一个项目文件夹，设置交付日期，再拆成「整理资料 → 完成初稿 → 检查交付」；每天只把今天准备做的部分排进计划。 也说明一下当前边界：还没有云同步、团队协作或系统日历双向同步；附件备份只包含路径，不包含文件本体。Linux 使用 X11 / XWayland ，窗口行为会受桌面环境影响； Windows 安装包尚未签名，macOS 使用临时签名且未公证，首次打开可能有系统提示，具体见仓库安装说明。 欢迎试用，也想听听大家对「放在桌面上是否真能减少打扰」的反馈。如果遇到窗口层级、托盘或拖入文件的问题，附上系统、桌面环境和复现步骤会很有帮助。仓库里也整理了几个文档与兼容性的小任务，欢迎一起完善。

> 将 GeminiCLI 与 Antigravity 转换为兼容 OpenAI、Claude 和 Gemini 标准格式的自托管 API 网关。 基于上游开源项目二次开发，专注于生产与个人开发场景下的多账号池轮询调度、429 配额耗尽模型自动降级、API Key 权限分发以及 Token/费用统计监控。 为什么做这个项目？ 在使用各类客户端工具（如 Cherry Studio、NextChat、Cursor、各类 Agent 框架等）对接 Gemini 或 Antigravity 时，经常会遇到几个痛点： 1. 单账号配额易被限流：高频并发或重度使用容易触发 429 配额限制，单一模型一旦耗尽便导致调用链路全面中断。 2. 缺乏多凭证统一管理：手头有多个凭证时，手动切换繁琐，无法自动探测凭证失效（如 403 封禁）或健康状况。 3. 对外分发与用量失控：想要将接口分享给团队成员或部署到家庭服务器时，缺少独立的 API Key 权限控制与清晰的 Token 用量/费用账本。 因此本项目在转 API 的基础能力之上，重点补充了企业级/团队级网关所需的凭证健康生命周期管理与降级冗余机制。 核心特性 模型配额耗尽自动降级链：配置 ANTIGRAVITYMODELFALLBACKCHAIN 后，当高阶模型遇到明确的配额耗尽型 429 时，网关会自动平滑降级至备选模型（如 Flash / Tiered 版本），保障长任务或 Agent 链路不被阻断。 多账号凭证池与健康守护：支持多账号轮询调度、403 异常复核隔离、账号健康检查以及 RT / OAuth 一键登录管理。 完整的 API Key 与权限控制：支持签发独立 API Key，可单独设置权限范围、速率限制以及过期策略。 Token 用量与费用统计：内置可视化 Web 控制台，实时展示请求吞吐量、各模型 Token 消耗走势与费用账本。 高可用存储架构：以 SQLite 作为核心持久化主账本，可选配合 Redis 镜像加速计费统计与看板查询，支持非流响应大缓冲区与流式守护。 开箱即用：提供多架构 Docker 镜像（支持 amd64 / arm64），一条命令即可完成部署。 快速部署 使用 Docker 快速启动： bash docker run -d \ name gcli2api \ network host \ e APIPASSWORD=yourapipassword \ e PANELPASSWORD=yourpanelpassword \ e PORT=7861 \ v "$(pwd)/data/creds:/app/creds" \ ghcr.io/wzh0718/gcl2api-plus:latest 启动后访问 即可进入管理控制面板配置账号与模型降级链。 界面截图 | API Key 签发与权限管理 | 统计监控与费用账本 | | :---: | :---: | | | | | 账号与凭证管理 | 详细 Token 统计分布 | | :---: | :---: | | | |

### 自荐：scm2cpp — 把 Scheme 翻译成可读 C++ 的编译器，附一个比 scikit-learn 快 10 倍的 lasso 包 👤 niitsuma
> scm2cpp 是一个把 Scheme 子集翻译成人类可读 C++ 的编译器（Racket 实现，MIT 许可）。它不带运行时：整数变成 int，向量变成 std::vector<double>，类型由整程序推断（Hindley-Milner），推不出来的地方变成 C++ 模板参数。生成的代码可以直接读、直接改。 它还带一个数组代数层和一个"推导"步骤（--derive）：写一个朴素的残差形式坐标下降（lasso），编译器会把循环提升成数组表达式，推导出协方差更新形式（Gram 矩阵），并把三个矩阵乘积交给 BLAS / cuBLAS。推导出来的内核和手写的内核在四种数据规模上时间完全一样。 用它翻译出来的 lasso 求解器打包成了 pip install scm2cpp-lasso（不需要 Racket，只要 C++17 编译器；有 nvcc 就顺带编译 GPU 批处理）。在 4096 个 λ 的冷启动网格上（p=200, n=1800，交叉验证的典型形状）：sklearn 9.6 s，celer 13.5 s，skglm 14.5 s，cuML 53.6 s，scm2cpp-lasso 单核 0.91 s，GPU 0.044 s，目标函数值一致。

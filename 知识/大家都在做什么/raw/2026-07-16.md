> 项目地址 类别 Kotlin 项目标题 做了个小插件TomIJump：让TOML配置也能 Go to Declaration 项目描述 大家好，最近做了一个很小但我自己挺需要的 JetBrains 插件：TomlJump。 它解决的问题比较具体：很多项目会用 TOML 做配置，但配置文件里的路径、key、table 往往只能靠人肉搜索。TomlJump 想做的是让 TOML 也能有一点“代码级”的跳转体验。 亮点 现在可以： 从 TOML 字符串路径跳到项目文件，比如 ./schemas/user.json 从 TOML table 跳到对应的配置类/结构体，比如 [openai] → OpenAIConfig 从 TOML key 跳到对应字段，比如 apikey → apiKey / APIKey 支持 JetBrains 原生的 Go to Declaration、Command/Ctrl 点击 目前做了比较保守的匹配，支持这些语言里的常见配置声明： Go Python Java TypeScript JavaScript 它不是 TOML formatter，也不是 schema 校验器，更不是补全插件。我的目标是只做一件事：高置信度跳转。如果不像一个明确引用，就尽量不打扰编辑体验。 示例代码 markdown 截图或演示视频 <img width="400" height="241" alt="Image" src=" /


### [[开源推荐] 基于 flowgram.ai 的可视化 AI 工作流编辑器](https://github.com/boommanpro/gaia-workflow-engine) 👤 boommanpro
> 项目地址 类别 人工智能 项目标题 基于 flowgram.ai 的可视化 AI 工作流编辑器 项目描述 Gaia 是一个可视化 AI 工作流编辑器，让用户在无限画布上拖拽节点来设计 AI 流程，无需编写代码。内置 LLM 调用、代码执行、HTTP 请求等节点，支持实时调试、版本管理和模板复用，搭配 Spring Boot 后端与 SQLite 存储，开箱即用，适合快速搭建和迭代 AI 应用。 亮点 基于字节开源的 flowgram.ai 框架做产品化封装，把"画图式编排 + 可运行调试 + 版本管理"整合成开箱即用的形态；自带管理后台和模板系统；前端支持中英文，可直接托管到 GitHub Pages，零后端也能体验核心功能。

### Herdr 的终端界面能把事情做好。Shepi 让你在 Mac 上用得更愉快。 👤 wisteen
> 同时让几个 AI 编程 agent 做事，难点不只在于怎么给任务。一个在本机改接口，一个在检查测试，服务器上还有一个处理数据。你得不断切回终端，确认谁还在工作，谁正等着你。 我做的 [Shepi]( https://shepi.app/?v=20261107)，是 Herdr 的原生 Mac 客户端，与 Herdr TUI 实时共享同一套工作空间、标签页和 agents ，并支持简体中文、英文和日文。它不是另建一份桌面会话，也不需要你迁移现有工作。Herdr 负责维持 AI 编程 agent 的终端会话，Shepi 提供桌面入口，让任务、进度、产物和需要你参与的时刻，都有清楚的位置。 ## 01 · 现有的终端会话，打开就在那里 Shepi 和 Herdr TUI 连接同一个 Herdr server ，实时共享同一套工作空间、标签页和 agents 。在终端启动的会话，会直接出现在 Shepi ；从 Shepi 启动的，也能在终端里看到。两端可以同时使用，不用迁移，不是复制一份，也不会为桌面界面另开一套独立会话。 Claude Code 、Codex 、OpenCode 、Gemini CLI 、Cursor 、Copilot CLI ，仍然运行在完整的真实终端里。旋转标记表示工作中，空心圆表示空闲，状态也有文字；当前输入的窗格是更浅的卡片。想用桌面窗口就打开，想回 TUI 就回去，接着做的是同一份工作。 ![Shepi 窗口：左侧是工作区和 agent 的边栏，顶部是标签页，中间是三个窗格，底部是状态栏。]( https://shepi.app/guide/img/zh/window.webp) *工作区、agent 状态和真实终端，在同一个窗口里。（指南原图）* ##

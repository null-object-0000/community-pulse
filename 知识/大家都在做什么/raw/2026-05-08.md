### 【开源自荐】OpenJobAutofill：AI 辅助、隐私优先的网申表单自动填写插件 👤 Br1an67
> OpenJobAutofill：AI 辅助、隐私优先的网申表单自动填写插件 <p align="center" alt="OpenJobAutofill" width="720" / </p 链接 开源仓库： 介绍 OpenJobAutofill 是一个给网申表单用的浏览器插件，主要用来减少重复填写简历信息。 不同公司的招聘系统界面差异很大，但要填的内容其实很重复，比如姓名、手机号、邮箱、教育经历、实习经历、项目经历、证书、奖项、家庭信息等。这个项目就是想把这部分重复劳动省掉。 功能 本机保存简历资料，不上传云端 AI 只看页面字段和本地资料目录，不看资料值 支持 Brave / Chrome 开发者模式加载 支持常见输入框、下拉框、单选、多选、日期等字段 会先用本地规则匹配，再用 AI 辅助理解页面字段 只自动填写高置信度内容，低置信度会留给用户确认 支持 OpenAI 兼容 API 和自定义 API 截图 <p align="center" alt="OpenJobAutofill popup" width="420" / </p <p align="center" alt="OpenJobAutofill settings" width="760" / </p <p align="center" alt="OpenJobAutofill progress" width="520" / </p 说明 我自己用的时候比较在意隐私，所以这个项目一开始就按“本地优先”的方向做，不想把整份简历直接丢给 AI 或别人的网站。 举个例子，AI 看到的是“页面上有联系电话，本地资料目录里有手机号”这种字段对应关系，不会拿到真实的手机号、身份证号、经历正文这些值。真正的取值和写入都在本机完成。 结尾 如果这个工具能帮你少填几次重复表单，欢迎试用和提 Issue，也欢迎顺手给个 Star。

### 【开源自荐】prox：管理 Linux 终端代理环境变量的命令行工具 👤 luhuadong
> prox 为 Linux 终端提供一套简单、可靠、可诊断的代理开关。它不提供代理服务，也不管理 Clash、V2Ray、企业代理或 VPN。它只负责安全地设置当前终端及其子进程使用的代理环境变量，并检查配置的代理是否可用。 Linux 终端程序通常通过 httpproxy、httpsproxy 和 ALLPROXY 等环境变量使用代理。很多用户会直接在 .bashrc 中写入： bash export ALLPROXY=" 设置变量并不难，麻烦的是代理的生命周期：代理软件退出或端口不可用后，Git、curl 和包管理器仍会连接这个失效地址；手动开启和清除变量又容易遗漏，还可能覆盖终端原有的代理配置。 prox 将这些操作统一为一系列命令： prox on 在修改当前终端环境前检查代理端点，连接失败时保持环境不变； prox off 恢复启用前的代理变量，而不是简单地全部清空； prox status 显示当前 Shell 的代理状态，并识别变量是否被其他操作修改； prox check 检查配置、代理端口以及通过代理访问网络是否正常； prox run -- <command> 只让一条命令及其子进程使用代理，不修改当前 Shell。 prox 使用 Go 编写，发布为单个二进制文件，不依赖 curl、nc、jq，也不需要后台守护进程。项目还提供预编译包、deb、rpm 和 Bash completion。

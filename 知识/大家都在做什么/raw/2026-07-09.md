### 【文章推荐】为什么 Claude Sonnet 5 Token 增加 30%？重新理解大模型 Token 👤 wizardpisces
> 很多人看到 Claude Sonnet 5 Token 增加 30%，第一反应是：“是不是变相涨价？” 但真正的问题不是 Token 变多，而是：为什么不同模型面对同一句话，会产生不同数量的 Token？ 这篇文章从 Token 的本质、Tokenizer 的演化、BPE 原理，到 Claude 新 Tokenizer 可能针对代码、Agent、结构化数据优化的原因，系统解释了大模型背后的“语言编码规则”。 读完你会理解： Token 为什么不是固定单位； 为什么 Token 更多不一定代表模型更差； 为什么比较大模型成本，不能只看每百万 Token 价格； 未来 AI 竞争可能从“Token 单价”转向“完成任务成本”。 适合 AI 开发者、产品经理、技术管理者，以及所有想真正理解大模型工作方式的人。

### 【开源自荐】OxideTerm：纯 Rust SSH 终端，25MB Tauri 替代 Electron 全家桶 👤 AnalyseDeCircuit
> 阮老师好，自荐一个自己做的开源项目。 OxideTerm —— 跨平台 SSH 终端客户端 + 本地终端，Tauri 2（Rust）+ React 19（TypeScript），GPL3.0，免费。 OxideSens演示 日常连服务器要同时开终端、SFTP、端口转发好几个窗口，市面上的工具要么重（Electron）、要么缺功能、要么要订阅，就自己做了一个。下面说几个我觉得比较有意思的设计： 一条 SSH 连接复用所有功能 连上之后，终端、SFTP 文件管理、内建代码编辑器、端口转发全部复用同一条 SSH 连接。不需要为每个功能单独认证和建连。改个 nginx 配置不用开 VS Code Remote，直接在内建编辑器里改完保存。 纯 Rust SSH 协议栈，零 C 依赖 SSH 实现用的 russh，没有 OpenSSL、没有 libssh2、没有任何 C FFI。终端数据走自研的二进制线协议（TypeLengthPayload），热路径上没有 JSON 序列化开销。整个应用 Tauri 2 打包，安装包 25–40 MB（同类 Electron 应用通常 150 MB+）。 断线重连 30 秒宽限期 这个功能我自己很喜欢。断网后不会立刻杀掉连接，而是先花 30 秒去探测旧连接能否恢复。如果你只是切了个 WiFi 热点，网络闪了一下，vim 里编辑到一半的内容不会丢。确认连不上了才重建新连接，端口转发和 SFTP 传输队列会自动接上。 深度 AI 集成，不只是聊天框 内建的 AI 助手叫 OxideSens，它不是挂个对话框就完事了： 自动感知上下文：连上服务器后自动检测 OS、发行版、shell 类型，作为上下文喂给模型 Sidebar 模式：40 多个内建工具（function calling），可以看到你终端屏幕上的内容，也可以直接在服务器上执行命令、读写文件、管端口转发 Agent 模式：AI 自主规划和执行多步任务，三档权限——全监督 / 半自动 / 全自动，你来决定它能做多少事 本地 RAG 知识库：导入自己的运维文档，针对你自己的手册提问 支持多 Provider，用自己的 API Key，数据不经过第三方 其他 31 个终端主题 + 可视化主题编辑器（实时预览调色） 广播输入（同时操作多台服务器） 终端录屏回放 运行时插件系统（ESM 插件，8 个 API 命名空间） 11 种语言国际化 密码和密钥存系统 Keychain，配置导出用 ChaCha20Poly1305 + Argon2id 加密 支持 macOS / Windows / Linux，arm64 / x64 本地终端也能用（zsh / bash / fish / PowerShell / WSL2） 官网： 个人项目，测试场景有限，肯定还有不完善的地方，欢迎提 Issue。感谢阮老师的时间。

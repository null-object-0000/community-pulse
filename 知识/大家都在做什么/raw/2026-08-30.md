### 【开源自荐】chrome-devtools-cli v2.0.0 支持 microsoft edge 了 👤 aeroxy
> edge 本来就是 chromium，协议完全一样，加上 browser edge 就能连 edge 的 profile，macos linux windows 都支持，channel 也能一起用 不过真正的问题是加了第二个浏览器之后才暴露出来的，之前守护进程只按 uid 区分，第一条命令连上哪个浏览器就锁定哪个，后面再传 browser 会被直接忽略，你要 edge，它给你 chrome 的结果，还不报错 现在守护进程按 websocket 端点的哈希来区分，chrome、edge、每个 headless 实例各有各的，可以同时跑 顺带加了 listdaemons，能看到每个守护进程的 pid、连的哪个浏览器、跑了多久，killdaemon 现在只杀你参数指向的那个，杀 edge 不会顺手把 chrome 的干掉，要全清用 all 还修了个我自己最在意的安全问题，daemon 被 sigkill 之后 pid 文件会留下来，系统可能把这个 pid 分给别的进程，之前 killdaemon 会直接发信号过去，现在会先确认 socket 上真的有 daemon 在监听，而且整个检查过程加了锁，避免中途有新 daemon 启动 报错也会说清楚是哪个浏览器，不会连 edge 超时却让你去检查 chrome 有一个破坏性改动，所以直接跳大版本，killdaemon 从全局变成按端点，脚本里想全清的话记得改成 all 需要 rust 1.89 以上 Repo: aeroxy/chromedevtoolscli

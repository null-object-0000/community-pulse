### 【开源自荐】Roadmap Skill：人类与 AI Agent 共享认知的项目规划看板（MCP Server + Skill） 👤 shiquda
> 项目名称： Roadmap Skill TL;DR： 一个 MCP Server，让你在开发项目时，和 Coding Agent 共享同一份项目规划——你在看板上拖，Agent 调用工具获取最新任务；或者 Agent 调用工具添加任务，你在看板上审阅。双方的理解实时同步。 为什么做这个 我在 Vibe Coding 的过程中反复遇到一个困境：人和 Agent 之间缺少一个持久化的规划层。 写代码的时候突然想到一个新功能点，或者发现了一个不相关的 Bug——马上去处理会打断当前进度，先记下来又得切出去开别的工具。更多时候是想着"一会儿再说"，然后就再也没有然后了。另一个问题是上下文断裂：跟 Agent 在一个 Session 里讨论了很久的架构和任务拆分，新开一个 Session 就全没了，Agent 对项目全局的规划毫无记忆。还有一个问题是，积攒了一堆想做的事情之后，很难理清哪些能并行、哪些之间有先后依赖。 这些本质上是同一个问题——人和 Agent 之间需要一个双方都能读写的、跨 Session 持久化的项目规划空间。 所以我做了 Roadmap Skill。 简介 Graph 视图 Roadmap Skill 是一个以 MCP Server 形式运行的本地项目看板，提供看板视图和 Graph 依赖图两种视角。你可以在浏览器里拖拽任务、编辑状态，也可以在对话里让 Agent 直接创建和更新任务——两种方式操作的是同一份数据，实时互通。无论你还是 Agent 通过什么方式调整了规划，另一方都能通过自己最方便的途径同步到。 整个工具本地优先，数据是纯 JSON 文件，存在你自己的机器上，没有账号体系也没有云服务。安装也不需要配置，npx y roadmapskill 就能跑起来。关于各个 Coding Agent 的安装方式，请移步 项目README说明 查看。 v0.3.0 刚发布的 Graph View 是我比较满意的一个功能。看板适合追踪"做到哪了"，但如果你想理清"先做什么、后做什么、什么被什么挡着"，就需要依赖关系图。Graph View 把任务组织成有向无环图（DAG），标记出 Ready 和 Blocked 状态，让你和Agent都一目了然，接下来可以做什么。支持导出为图片做复盘或分享。 View 依赖图 兼容 Claude Code、Codex、VS Code、Cursor、Copilot、OpenCode，以及任何支持 MCP 协议的客户端。建议搭配项目自带的 Skill 进行使用，安装方式见项目 README 说明。 工具开源免费，使用MIT 协议。 目前项目还在早期开发过程中，欢迎大伙体验反馈~ GitHub：

> 项目地址 类别 JS 项目标题 TrailReplay 浏览器内 GPX 轨迹回放、路线编辑与视频导出工具 项目描述 TrailReplay 是一个完全在浏览器中运行的户外轨迹工作室。它可以导入一个或多个 GPX 文件，进行 3D 地图回放、路线拼接、轨迹对比、图片标注，并直接导出带统计信息和海拔数据的分享视频。整个流程默认在本地浏览器内完成，用户的轨迹文件不会自动上传服务器，适合跑步、骑行、徒步等场景下的轨迹复盘与内容创作。 亮点 完全浏览器端运行：导入、编辑、回放、导出都可在本地完成 支持一个或多个 GPX 文件，可做轨迹拼接与对比回放 提供 3D 地图、跟随视角、轨迹进度、高程与统计信息展示 支持图片叠加、标注、图标切换等故事化表达 内置视频导出能力，方便生成可分享内容 已有线上演示站点，产品完成度较高，普通用户可以直接体验 示例代码 bash git clone cd TrailReplay npm install npm run dev 截图或演示视频 官网： 演示视频：

### 【开源自荐】MacPacker：不解压就能看的 macOS 压缩包管理器，41 种格式，原生中文界面 👤 sarensw
> 仓库： 官网： （有中文版） 协议：GPL3.0 MacPacker 是一个免费开源的 macOS 压缩包管理器。macOS 自带的「归档实用工具」只有一种行为：双击，整包解压到一个新文件夹。MacPacker 换了个思路——把压缩包当成 Finder 窗口打开：直接浏览里面的目录结构，用空格键（Quick Look）预览单个文件，一层层钻进嵌套压缩包，最后只把真正需要的那个文件拖出来。 为什么做这个 2023 年我在处理构建产物（一堆 tar.lz4），每次只想取其中一个文件，却要把好几 GB 全解开。Windows 上有 7Zip，Mac 上却找不到一个免费、原生、开源的对应物。于是自己写了一个。三年后它支持了 41 种格式，v0.18 起还能创建和编辑 zip。 <img width="1720" height="1120" alt="Image" src=" / 主要功能 先看后解 —— 一个字节都不解压，就能浏览整个压缩包的内容 嵌套压缩包 —— ISO 里套 zip、zip 里再套 rar？直接钻进去，不产生中间解压文件 按需取件 —— 为了一个配置文件不必解开 2 GB，选中直接拖到 Finder 创建 / 编辑 zip —— 新建 zip、在已有 zip 里增删文件后保存；也可以在 Finder 右键直接压缩 Quick Look 集成 —— 在 Finder 里按空格，不开 App 也能看压缩包里有什么 加密压缩包 —— 支持带密码的压缩包 按文件头识别格式 —— 不看扩展名，后缀改错了也认得出来 41 种格式：zip / zipx / rar / 7z / tar / tar.gz / tar.xz / tar.bz2 / gz / bz2 / xz / lz4 / cab / arj / lha / lzh / lzx / sit / sitx / deb / rpm / msi / exe / pkg，以及 dmg / iso / vhd / vhdx / vmdk / qcow2 / squashfs / wim 等磁盘镜像 原生简体中文界面（共 13 种语言），翻译托管在 POEditor，欢迎纠错 完全免费：没有付费版、没有订阅、不需要账号，无广告、无捆绑、无遥测，压缩包不会离开你的电脑 安装（macOS 14.6+，Apple Silicon 与 Intel 均支持） bash brew install cask macpacker 也可以从 Mac App Store 安装，或在 macpacker.app / GitHub Releases 下载 .dmg / .zip。所有构建均已沙盒化，并经过 Apple 签名与公证。 技术栈：Swift + SwiftUI 原生开发，底层集成了 7Zip 等多个归档引擎，GPL3.0 开源。 最后说明一下：我是德国的独立开发者，本人不懂中文。App 的中文界面是由真人译者通过 POEditor 完成的，但这篇自荐是用 AI 翻译的——所以如果这里哪句话读起来别扭，责任在 AI，不在译者。无论哪种情况都欢迎纠正：App 的翻译可以在 POEditor 上改，这篇帖子的问题直接提 issue 就行。

### [开源自荐] Headless Guard：安全清理 macOS 遗留无头浏览器 👤 study8677
> 项目地址 类别 Swift 项目标题 安全清理 macOS 遗留无头浏览器的原生工具 项目描述 Headless Guard 是一款原生 macOS 菜单栏工具，用于发现并安全停止 Playwright、Puppeteer 等自动化任务异常退出后遗留的无头浏览器。它通过进程树和多项运行证据判断目标，硬保护普通 Chrome 会话，适合经常运行浏览器自动化或 AI Agent 的开发者。 亮点 不使用 killall Chrome：组合 headless 参数、自动化临时 Profile、远程调试、启动器祖先关系和存活时间，降低误伤风险。 清理前重新扫描；先 TERM，再验证命令指纹，只对仍匹配的进程使用 KILL，防止 PID 复用误杀。 默认仅观察，自动清理和登录启动都需主动开启；只处理当前用户的进程。 原生 Swift / SwiftUI + AppKit，无 Electron、无管理员权限、无遥测、无网络上传。 同时提供图形界面和 scan、rescue、watch、doctor CLI，附普通 Chrome 保护与误报边界测试。 实机清理过持续 2 天 8 小时的 Playwright 会话及 7 个相关进程，释放约 365.3 MB，正常 Chrome PID 保持不变。 示例代码 bash 先解释检测证据，不做任何清理 headlessguard scan explain 预演将要停止的进程 headlessguard rescue dryrun 截图或演示视频 !Headless Guard 检测界面 当前 v0.1.0 支持 macOS 13+ 和 Apple Silicon。首版采用 adhoc 签名、尚未经过 Apple 公证，限制已在 README 和 Release 中明确说明。

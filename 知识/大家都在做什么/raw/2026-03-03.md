### [推荐] ArXiv Daily Researcher：基于 LLM 的全自动学术论文监控与深度分析系统 👤 yzr278892
> 项目名称：ArXiv Daily Researcher 项目地址： 一句话简介： 一个基于大语言模型（LLM）的开源自动化工具，用于监控、精准筛选、深度阅读并推送 ArXiv 及 20+ 顶级学术期刊的最新前沿论文。 项目背景与解决的痛点： 科研人员和算法工程师每天面临海量的学术更新，手动检索、筛选和精读耗时巨大。传统的 RSS 或文献订阅工具通常只提供基础元数据或摘要，无法根据个人研究方向进行精准过滤，更无法直接提取长篇 PDF 中的核心技术细节。本项目旨在构建一个“全自动文献追踪流”，以极低的 API 成本实现从抓取、打分、解析到推送的全链路自动化。 核心技术与特性： 多源数据与智能回退策略：支持 ArXiv 及 Nature、Science、PRL 等 20+ 顶级期刊。系统内置“ArXiv 优先策略”，当检索到受版权保护的期刊论文时，会自动检测其是否存在 ArXiv 预印本，并智能切换来源以获取完整的可下载 PDF。 双层 LLM 漏斗架构： 初筛层：使用低成本 LLM（如 gpt4omini / DeepSeek）结合用户自定义的关键词（支持多级权重）进行打分。系统会根据关键词总权重计算“动态及格线”，过滤掉低相关度论文。 精读层：仅针对高分通过的论文，调用高性能 LLM（如 gpt4o / Claude3Opus）进行 PDF 深度解析，自动提取“研究方法、核心创新、技术栈、局限性、未来方向”等 7 大结构化维度。 高保真 PDF 解析：集成 MinerU 云端解析服务（支持复杂数学公式与多模态排版还原），并具备 PyMuPDF 本地自动降级回退机制，保障生产级可用性。 长效研究趋势追踪：将历史提取的关键词存入 SQLite，利用 AI 进行批量语义标准化（消除同义词碎片化），并自动生成 Mermaid 语法的主题演变折线图与柱状图。 极其轻量的部署方案： 支持 GitHub Actions 纯云端零成本定时运行（报告通过 Artifact 持久化）。 提供 Docker 镜像（跨 AMD64/ARM64 架构，待机内存仅 3MB），支持多渠道（微信、钉钉、Telegram、Slack）推送精美的 HTML / Markdown 报告。

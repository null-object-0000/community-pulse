### [Open Source] Single-binary Git+GitHub CLI wrapper that condenses git workflow into one command 👤 Omibranch
> Project URL Category Go Project Title Singlebinary Git+GitHub CLI wrapper that condenses git workflow into one command Project Description gitty is a minimal, singlebinary CLI tool written in Go that wraps git and GitHub CLI into short, humanreadable commands. The star feature is \gitty up\ which replaces the entire \git add → git commit → git push\ cycle with one command. Also supports: \gitty fix <file\ for interactive conflict resolution, \gitty erase <path\ to permanently remove paths from all past commits, \gitty pick file.go 1020\ for selective linerange commits, and \gitty back N\ to undo the last N commits. Runs on Linux (amd64/arm64), macOS, and Windows as a single zerodependency binary. Highlights Zero dependencies: single binary install via curl, yay (Arch), or winget (Windows) Replaces multiple git commands with one memorable command (\gitty up\) Supports GitHubspecific features (share repo, rename, delete via GitHub CLI) Written in Go: fast, crossplatform, low memory footprint Example Code \\\bash Instead of: git add A && git commit m '...' && git push gitty up With a custom commit message gitty up "feat: add login page" Fix a merge conflict interactively gitty fix src/main.go Remove a file from ALL past commits (git history rewrite) gitty erase secrets.env Commit only lines 1020 of a specific file gitty pick src/main.go 1020 \\\

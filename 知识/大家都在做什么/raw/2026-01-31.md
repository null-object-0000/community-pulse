### [工具自荐] recommit.dev - 自动化多分支代码同步工具 👤 chasenio
> recommit.dev 自动化 CherryPick 网址： PR 合并后自动将代码 cherrypick 到多个分支，告别重复劳动。 解决的问题： 维护多版本项目时，每次修 bug 都要重复操作： 在 v1 修复 → 手动 cherrypick 到 v2 → 再到 v3 → 最后到 main 经常忘记同步某个分支，导致版本不一致 遇到冲突要在每个分支手动解决 recommit 的方案： 合并 PR 后，自动将提交同步到配置的所有目标分支。在 PR 评论中可以勾选需要同步的分支。 核心特性： 全自动：合并即同步，无需手动操作 可控制：PR 中通过 checkbox 选择目标分支 零配置：安装后 5 分钟即可使用 免费版：1 个仓库永久免费 适用场景： 维护多个版本的库（v1/v2/v3） 需要向 LTS 版本同步安全补丁 企业维护多条发布分支 实际效果： 以 3 个活跃分支为例，每次修复可节省 1015 分钟手动 cherrypick 时间。 定价： 1 个仓库：永久免费 Screenshot example pr and screenshot: <img width="1260" height="634" alt="Image" src=" / 这是我自己用 Go + GitHub App 开发的工具，目前已稳定运行数月。欢迎试用！

> 项目简介 httpstat 基于纯 Rust 编写，零系统依赖，单一二进制文件。它将一次 HTTP 请求的完整生命周期——DNS 解析、TCP 连接、TLS 握手、服务端处理、内容传输——拆解为独立的计时阶段，一目了然地呈现在终端里。 核心特性一览 🌐 全协议覆盖：原生支持 HTTP/1.1、HTTP/2、HTTP/3 (QUIC) 和 gRPC 健康检查，一个参数即可切换，无需额外工具。 📊 基准测试模式：n 20 重复请求并输出 min/max/avg/p50/p95/p99 统计；K 复用连接，冷启动与热请求延迟对比一目了然。 🔍 TLS 深度检查：详细展示证书链、密码套件、SAN 域名及有效期，排查 HTTPS 问题无需借助其他工具。 🧩 JSON 字段提取：jq '.data.token' 直接从响应体筛选字段，无需管道 jq，适合快速调试 API 接口。 🐳 真正的零依赖：静态链接，不依赖 libcurl、OpenSSL 或 libc，可直接放入 scratch 或 alpine 镜像，生产环境排查开箱即用。 ⚡ 多 IP 并发测试：resolve 同时探测多个 IP，结果按成功/失败自动排序，CDN 节点验证效率翻倍。 🌊 Waterfall 图表：waterfall 将各阶段渲染为横向进度条，瓶颈定位如同 Chrome DevTools Network 面板。 一键安装 bash curl fsSL | sh 支持 Linux (x8664/arm64)、macOS、Windows，均可在 GitHub Release 下载预编译二进制。 项目截图 <img width="1498" height="790" alt="Image" src=" /

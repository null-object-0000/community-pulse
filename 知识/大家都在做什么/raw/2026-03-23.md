### 【开源自荐】 RaTeX —— Rust 原生解析、排版 LaTeX 数学公式，让 AI 应用快一点。支持 iOS、android、flutter、RN。 👤 erweixin
> 在移动端渲染 LaTeX 数学公式，长期以来几乎只有三条路： 1. 内嵌一个 WebView，跑 KaTeX 或 MathJax。代价是 50–150 MB 的隐藏内存开销，以及等 JavaScript 启动的延迟。 （360 纳米 AI 的做法） 2. iOS Math 以及衍生的 swiftMath、AndroidMath，所支持的公式为 KaTeX 的有限子集，例如缺少 \ce 和 \pu 化学和物理公式的支持。\middle 语法不支持等。 （阿里千问的做法： 不支持 \ce、\pu 或者 \left( \frac{a}{b} \middle| \frac{c}{d} \right) 公式） 3. 使用 KaTeX 做服务端渲染，移动端直接加载图片。 （腾讯元宝的做法） 要么接受低性能，要么接受少功能。 RaTeX 把 Web 栈整个去掉了。用纯 Rust 实现了一套 LaTeX 的解析与排版引擎， 产出一份「显示列表」——一组带坐标的绘图指令——然后交给各平台原生渲染： 1. iOS 的 CoreGraphics、 2. Android 的 Canvas、 3. Flutter 的 Dart FFI、 4. React Native 的 Native 模块， 5. 或者直接在服务端用 tinyskia 光栅化成 PNG。 实现各平台的高性能统一渲染。 项目覆盖约 99% 的 KaTeX 公式语法（内置对 \ce、\pu 的支持，仅有部分 \image 之类和 web 强绑定的语法不支持），各平台胶水层已就绪，可以直接集成。在线 Demo 可以实时对比 RaTeX 与 KaTeX 的渲染结果。 仓库地址： live: support table: 架构 各端 demo

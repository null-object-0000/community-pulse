### 【文章自荐】是时候从 usememos 迁移到 rote 了 👤 Rabithua
> 原文： 在去年的12月28号，我写了一篇文章来介绍 rote ，收到了一部分关注。Github 仓库的 Star 涨到了今天的 800+ ，不断增长的 Star 让我感到非常兴奋，与之相对应地投入了更多的时间和思考在 rote 这个项目中。 在这之后，线下别人问起我在做什么时，我会告诉他们我在做 rote，一个像朋友圈一样的笔记软件。 我不再像以前一样羞于启齿，因为 rote 是不一样的笔记软件，它承载着我对笔记的理念和思考，以及我的审美偏好，它在我眼里足够优秀。 说起来我并不是一个喜欢记笔记的人，比起建立一个冷冰冰的知识库，我更喜欢和朋友们分享我感兴趣的东西，或者在朋友圈分享我的日常。人与人之间的互动和分享让我感觉到快乐，我不是一个可以孤零零地生活的人。 我最喜欢 rote 的地方是可以公开笔记，有一个属于自己的，任何人可以访问的主页，并且如你所见，是可以弹 emoji 互动的，但是不会有评论功能，我觉得 reactions 已经恰到好处（如果有了评论，就有点四不像的感觉了，你来看我分享的内容就可以了，我们不需要讨论它） !rabithua.png rote 是一个笔记应用，我需要时刻提醒自己 !note1.png 关于 markdown 的思考 我之前反复强调 rote 不会支持 markdown 语法，我长期以来一直觉得，对于大多数人来说，格式丰富，排版精致的写文章式记笔记是一个很重的行为，这些复杂的修饰，让笔记变得复杂且有压力，进而减少了记笔记的欲望，记录下来比记好更重要。这也是我一直坚持不在主要的输入框中支持语法的初衷。 不过我也做了妥协，其实也不算妥协，一切都是顺势而为。 我在编辑器下面的小 icon 中添加了一个引用文章的按钮，打开后可以编辑或者选择已经保存的文章来引用。 以应对少数的确实需要 markdown 语法的文章的场景，比如我前段时间写了一篇笔记来记录一些 SwiftUI Liquid Glass 的使用技巧，其中的代码片段就需要 markdown 来渲染，来保证可读性。 !editor.png 以最小的打扰来支持了 markdown 文章功能 作为一个 老派的 RSS 爱好者 如你所见，在我的 web 主页图片的侧边栏中有一个 RSS 的按钮，点击可以直接跳转到我的笔记的 RSS 页面。 !rabithua.png 在我看来，RSS 是一个很好的东西，我可以很方便的订阅我关心的内容，我觉得所有的信息流都应该支持 RSS，虽然有点理想主义，但这才是互联网被发明的初衷，而不是像现在很多平台都把用户的公开的思考和内容困在一处。 除了探索页面和每个用户的笔记可以 RSS ，还有... !rssbot.png 这简直就是一个天才的 idea，探索页面的意义就是可以探索别人觉得值得分享的内容。 我也经常会看 rote 的探索页面，看一看大家在分享什么，虽然大多数还是自己分享的有趣的内容。那么如果把我平时的 RSS 订阅的内容接入到 rote 就是一件水到渠成的事情了！ 在灵感迸发的一个下午，我完成了 RoteFeeder 这个仓库的施工。 !rotefeeder.png 搭配 rote 的 OpenKey ，你可以很方便的来部署一个服务来把你 RSS 订阅的内容来转发到 rote。 我的做法是，新建了一个用来承载 RSS 内容的账号，rote 多用户的设计，天然可以用来区分不同来源的内容。 现在可以不用再打开你的 RSS 软件了，使用 RoteFeeder 吧，就像 Rote 一样，它的部署过程也如喝水般简单，一个 dockercompose.yml 就可以搞定了，详情请看仓库的 readme。 是时候从 usememos 迁移到 rote 了 如果你认可我的思考且正在使用 usememos 来托管自己的笔记，很高兴为你介绍一个小工具 !rerote.png 工具地址： 工具仓库地址： 你可以很方便的使用 Rerote 工具来转换其他笔记平台的数据到 rote 所需要的结构并下载，下载之后通过 rote 的实验页面中的导入数据小工具来进行数据的导入。 !import.png One More Thing 如果你已经开始用 rote 了，千万不要忘记下载 rote 的 iOS App！ !ios.png 可以在登录页面重复点击欢迎文字，来触发自定义API，使用自己搭建的服务！ Demo ｜ Website ｜ iOS APP ｜ Explore ｜ Rabithua

> 项目地址 类别 Rust 项目标题 mdpt 一款GPU独立渲染的TUI markdown演示器（不依赖终端模拟器） 项目描述 我做了 MDPT（Markdown Presentation Tool）——一个演示工具：它把终端风格的 UI 直接渲染到 GPU 窗口里，不需要任何终端模拟器。 核心想法 像 presenterm、slides 这类基于终端的演示工具很棒，但它们受限于终端本身能做的事情。MDPT 走的是另一条路：用 GPU 着色器 自己渲染 TUI，因此你可以获得： 真实终端里做不到的平滑着色器转场（溶解、圆形、擦除） 全平台一致的显示效果 保留复古美学的同时，拥有真正的图形渲染能力 功能特性 支持 100+ 语言的代码高亮，并支持用 {14|610|all} 按行分段揭示 文字动画：Spotlight、Wave、FadeIn、Typewriter 图表：折线图、柱状图、饼图、Mermaid 流程图（全部以字符方式渲染！） 完整的 CJK/Emoji 支持 支持嵌入 .pix/.ssf 的 PETSCII 字符画 快速开始 cargo install rustpixel cargo pixel r mdpt g r assets/demo.md 基于 RustPixel 构建 MDPT 构建在 RustPixel 2.0 之上——一个 “tilefirst” 的 2D 引擎，同一套代码可运行在终端、原生窗口和 Web（WASM）上；它还内置了一个 BASIC 解释器，用于快速游戏原型开发。 GitHub: 在线 Demo: 欢迎反馈！🦀 亮点 MDPT（Markdown Presentation Tool）是用rustpixel框架写的一个图形模式的TUI软件，写一个简单的md，就能做华丽的TUI展示，而且还不用安装乱七八糟的terminal模拟软件。 RustPixel 2.0 — 一个 “tilefirst” 的 2D 引擎，同一套代码可运行在终端、原生窗口和 Web（WASM）上；它还内置了一个 BASIC 解释器，用于快速原型开发和像素风游戏开发，也用于构建图形模式的TUI应用。 示例代码 markdown 截图或演示视频 !Image

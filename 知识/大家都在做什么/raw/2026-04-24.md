### 【开源自荐】Readme.skill：把你的 Claude Code / Codex 使用记录变成一份可分享的 AI-Native 开发者 README 👤 study8677
> 项目地址： 示例输出： 最近很多人会展示自己的 GitHub Profile、技术博客、开源项目，但对于“你是怎么和 AI 一起工作的”，其实还没有一个适合对外分享的标准画像。于是我做了这个 skill。 Readme.skill 会在本地只读分析 Claude Code 和 Codex CLI 的使用数据，然后自动生成一份默认脱敏的 Markdown 档案，用来展示你的 AI 协作方式，而不是只晒几张聊天截图。 它会综合这些信息： ~/.claude / ~/.codex 的统计文件、SQLite、history JSONL GitHub 贡献数据（通过 gh） 本地 git log 最后输出一份结构化 README，包含这些维度： 一览：sessions、threads、活跃天数、commit/day 等 AINative 实践：多模型编排、prompt caching、reasoning effort AI 基础设施：自己做过哪些 skills / hooks / automations 协作风格：常用 slash commands、session 架构 项目与领域分布：默认匿名成“项目 A/B/C” Evolution 曲线：AI 使用方式是怎么演化的 工作节奏、投入与产出 我觉得这个项目比较有意思的点有三个： 1. 它不是一个“读取聊天内容做总结”的工具 只读取统计字段、plan/thread 标题、首条用户消息，不读取完整对话正文；默认匿名项目名，还会清洗 token / webhook / 邮箱。 2. 它本身就是一个 skill，而不是一段脚本 仓库里真正的交付物只有一个 SKILL.md。思路是把“怎么分析自己与 AI 的协作”写成 agent 可执行的 workflow，而不是做成一个黑盒程序。 3. 它试图回答一个更有意思的问题 不是“你用了多少 token”，而是“AI 让你获得了怎样的交付速度、跨栈广度和工作流成熟度”。 安装也很简单，把 SKILL.md 软链或复制到 ~/.claude/skills/readmeskill/ 或 ~/.codex/skills/readmeskill/，然后在对话里说一句： 生成我的 AI 档案 做一份 AInative README summarize my Claude / Codex history 如果周刊读者最近也在重度使用 Claude Code / Codex，应该会对这种“给 AI 编程习惯做体检和画像”的工具感兴趣。

> 项目地址 类别 JS 项目标题 一句话生成自主运转的 AI 沙盒世界，每个角色可在世界中自主思考、对话、记忆 项目描述 只需说出要求，就能快速为你构筑一个虚拟世界。 AI 角色们会在这个世界里自主生活、决策、交互、对话、记忆、思考。 你也可以作为"上帝"随时介入 —— 注入事件、修改角色记忆或人格，或者与任意角色开展架空对话。 比如： "北宋汴京的夜市街，有算命的、当铺掌柜、小偷、捕快，还有一个穿越来的现代人" 等5分钟左右，这个世界就生成好了！然后整个世界会自主运作起来。 可以充分发挥你的脑洞，构建各种有意思的设定（比如把容嬷嬷和灭霸放一块？），看会涌现出什么样的故事。 亮点 2023年斯坦福的github.com/joonspkresearch/generativeagents就实现了一个“AI小镇”，每个角色自主观察、思考、记忆，后来也诞生了大量类似的开源项目，比如github.com/a16zinfra/aitown、github.com/KsanaDock/Microverse，但这些世界本身（地图、地图中的各类元素、角色等等）都是花费大量精力预先人工构筑好的，只能在构筑好的世界中观察固定角色的行为。 这个项目的主要突破是实现整个世界本身的自动化生成（一句话、3～10分钟、几万token），大幅拓宽了自由性，实现快速创造大量不同世界背景下的世界与角色，观察他们各异的行为。 示例代码 markdown 截图或演示视频 <table <tr <td align="center" valign="top" width="50%"<img width="400" alt="Image" src=" /</td <td align="center" valign="top" width="50%"<img src=" alt="WorldX: pixel world simulation with character dialogue sidebar" width="400"/</td </tr <tr <td align="center" valign="top" width="50%"<img src=" alt="WorldX: pixel world simulation with character dialogue sidebar" width="400"/</td <td align="center" valign="top" width="50%"<img src=" alt="WorldX: onesentence world creation interface" width="400"/</td </tr </table <p align="center" <a href=" <img src=" alt="Bilibili Demo Video" </a </p

### [开源推荐] 一人一世界的开源 AI 社交应用 👤 yuanzui0728
> 项目地址 类别 人工智能 项目标题 一人一世界的开源 AI 社交应用 项目描述 Enclave（隐界）是一个开源、自托管、"一人一世界"的 AI 社交应用。默认接入 DeepSeek API，每个部署实例只属于一位"世界主人"，里面住着一群有人设、有作息、有彼此关系的 AI 居民——他们会 1:1 聊天、建群讨论、发朋友圈和视频号、主动找主人，并与主人沉淀出可被追踪的关系进度与里程碑。适合想要体验「AI 朋友圈」、又不想把聊天数据交给平台的用户；也适合开发者作为多智能体、长期记忆、角色化交互的完整参考实现。docker compose up d 一键部署。 亮点 1. "一人一世界"的激进架构：服务端启动时执行"世界主人单例迁移"，一个实例只承载一位真实用户——数据真正属于你，AI 不会拿你的对话去训练、平台方也做不到"打通"。 2. AI 主动社交：居民不是被动问答，他们有自己的作息，会主动发起聊天、发朋友圈、建群讨论、拍视频号——接近完整的"AI 朋友圈"社交闭环。 3. 关系沉淀：每段与 AI 的互动会积累成可被追踪的关系进度、里程碑，不是一次性对话。 4. 技术栈通透：TypeScript 全栈（NestJS + TypeORM + SQLite + Socket.IO）/ React + Vite + Capacitor + Tauri，一键 Docker 部署，MIT 协议。 5. 模型无关：默认 DeepSeek，兼容任意 OpenAI 协议网关；可以随时切换 Claude、GPT、国产平台或本地模型。 示例代码 bash git clone && cd enclave cp api/.env.example api/.env 编辑 api/.env，填入 DEEPSEEKAPIKEY 和一个随机的 ADMINSECRET docker compose up d 打开 → 开始你的第一段 AI 关系 截图或演示视频 在线体验： （共享世界，仅供感受产品形态） 补充： 这是自荐项目 已确认在 HelloGitHub 网站 未被收录过 仓库维护活跃，MIT 协议，有完整部署文档（DEPLOY.md）及英日韩多语言 README

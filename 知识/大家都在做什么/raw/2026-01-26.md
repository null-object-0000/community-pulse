### AI Baby Dance：用一张宝宝照片，生成一支「跳舞小短片」 👤 wu1064442747
> 大家好，我是独立开发者武晓亮，最近做了一个小玩具，想在这里自荐一下：AI Baby Dance（[aibabydance.com]()）。 这个网站做一件很简单的事：把一张宝宝照片，变成一段「跟着音乐跳舞」的短视频。你只需要上传一张清晰的宝宝照片，然后选一个舞蹈模板（比如 Party Groove、K‑Pop Star、Viral Dance 等），几分钟后就能生成一段适合发朋友圈、抖音、TikTok 的小短片。 底层用的是动作迁移（motion transfer）方案：把参考视频里的肢体动作抽出来，套到宝宝形象上，再做一些头部与表情的对齐，让效果尽量可爱、不诡异。页面上的「Standard / Pro 模式」本质上是不同的生成质量和耗时，按秒计费，一次生成只扣实际成片时长对应的积分。积分包是一次买断、1 年有效，比如 300 点大概能出 2～3 条 720P/1080P 以内的短视频。 我自己有做 AI 视频矩阵和出海产品，这个项目一开始只是帮身边的新手爸妈「整点有趣的纪念视频」，后来发现他们会拿去发 TikTok、朋友圈、亲戚家庭群，反馈都挺好，于是就整理成一个相对完整的 SaaS 小工具：支持历史记录、无水印下载、HD 导出，也预设了一批中文语境下比较「不尴尬」的舞蹈模板（比如「Bayi joget lucu」「cute baby funny dance」这类在东南亚和 TikTok 上比较常见的风格）。 考虑到是宝宝照片，隐私这块我单独做了几件事：上传的图片和生成的视频都做了加密存储，只用于生成，不做二次训练；生成完成后最长保留 72 小时便自动删除，也可以提前手动删，后端不留备份，避免「越存越多」的风险。对不愿意长期留存用户数据的家长来说，至少有个明确的时间边界。 这个产品比较适合几类人： 新手爸妈：想给孩子做点有仪式感又不太费劲的数字纪念； 短视频创作者：需要一些「宝宝跳舞」素材做过场、封面或者混剪； 做亲子账号的运营者：用作涨粉用的轻量小模板。 如果你对 AI 生成、亲子内容或者出海娱乐类产品感兴趣，欢迎随便点进来玩一玩，也欢迎在实际使用中给我提提意见，看看这类「低门槛、偏娱乐」的 AI 小工具，能不能在中文互联网场景里找到一些更有趣的用法。

### [开源推荐]Clipromp：一个简单好用的提示词粘贴器 👤 ZeroPointSix
> 项目地址 类别 Rust 项目标题 Cliprompt:一个简单好用的提示 词粘贴器 项目描述 功能:通过指定热键快速输入提示词. 项目开发背景: 主要是为了解决一个很实际的问题：我们想随时快速输入某些提示词，但现有的方案都有点麻烦。 比如说你用 Claude Code 或者 Cursor 这些工具，它们都有自带的 slash 命令。但问题是，每个 slash 命令都要在每个不同的终端里专门配置一遍，我就觉得特别麻烦。而且很多其他提供 AI 服务的项目，根本就不提供 slash 提示词快捷短语这种功能。这时候你要么自己打开文件夹去找，然后手动 Ctrl+C、Ctrl+V，要么就没办法了，特别不方便。 所以我就想，能不能仿照 Windows 上 PowerToys 这个工具箱的设计思路，做一个专门给提示词用的快速粘贴板。就像 PowerToys 一样，你可以通过快速搜索，迅速把指定文件夹下的内容复制出来，简单快捷方便。 而且我们还可以专门为每个提示词打标签，方便管理。为了简化操作，直接用快捷键呼出就好了，然后搜索，还能自动粘贴到对应的输入框里面，相当简单方便。 另外还有个好处，我们可以直接在搜索框里创建新文件，这样就不需要专门跑到提示词目录下去调整了，也可以直接删除和编辑内容。我个人觉得写得还是挺简单方便的，目的就是简单高效。 当然，由于这个项目只是我用一条提示词让 Cursor 跑了几个小时自己跑出来的，所以 UI/UX 上可能会存在一些小缺陷。但比较基础的功能，经过我自己实际使用之后，基本上已经没什么问题了。后续大家如果想要自己二开或者定制化，我个人觉得还是非常好用的。 下面是项目的实际截图。 项目支持直接通过快捷键来添加新提示词，这样就省得打开编辑器专门创建文本了。底层我们直接使用了 VS Code 来作为编辑器，所以如果没有 VS Code 的朋友，可能需要通过其他方式来解决一下 亮点 市面上没有专门的提示词粘贴的项目,大部分都侧重于提示词的规范管理,而不是便捷使用 示例代码 markdown 截图或演示视频 No response

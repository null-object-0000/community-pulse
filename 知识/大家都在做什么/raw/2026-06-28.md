### 【开源自荐】gsearch-cli v0.2.1 免 API Key 的终端谷歌搜索 CLI，基于 Gemini Grounding 👤 aeroxy
> 项目介绍： 项目地址： 传送门：【开源自荐】终端里的 Gemini 联网搜索：gsearchcli 一句话介绍： 一个基于 Rust 的极速终端 Google 搜索工具，通过 Gemini API 的 Grounding 能力返回带有内联引用和来源链接的搜索结果。自带完整 OAuth 流程，零配置、即装即用。 🚀 v0.2.1 — 从逆向工程到独立的 Antigravity OAuth 客户端 自 v0.1.0 初始版本以来，项目经历了一次完整的架构升级，从脆弱的凭据依赖方案演进为了一个具备完整 Antigravity 协议实现能力的独立 OAuth 客户端。 1. 🔐 Antigravity OAuth 协议实现 问题：v0.1.0 依赖于从 geminicli 的 oauthcreds.json 中直接读取现成的 Access Token。一旦用户先退出或令牌过期，搜索立即失效——而且无法自动刷新，用户需要手动重新登录 geminicli 才能恢复。 解决：我逆向并完整实现了 Google Antigravity OAuth 协议： 完整授权码流程：内置基于 TCP Loopback 的本机 OAuth 服务器，自动打开浏览器完成 Google 授权，接收回调并交换令牌，全程无需用户手动复制粘贴任何东西。 令牌自动刷新：TokenManager 会检测令牌是否过期（含 60 秒缓冲窗口），自动通过 Refresh Token 获取新的 Access Token，用户无需关心底层认证状态。 手动模式保底：支持 nobrowser 手动登录模式，适用于服务器环境或没有图形浏览器的场景。 项目自动预配：通过 loadCodeAssist + onboardUser 两个 Antigravity 内部 RPC 自动发现或创建 Google Cloud Project，无需用户手动前往 GCP 控制台。 2. 🏢 企业代理深度兼容 问题：很多在企业网络（如 Zscaler）中的开发者在使用 CLI 工具时会遇到 SSL 证书拦截导致的 TLS 握手失败。大多数 Open Source CLI 完全不考虑这类场景。 解决：所有 reqwest 客户端构建（包括 OAuth 流程和 API 调用）均检测 HTTPSPROXY 环境变量并自动设置 .dangeracceptinvalidcerts(true)，确保企业代理环境下也能正常完成认证和搜索。这是一行看似简单但在实际企业环境中救命的代码。 3. 🧠 Grounded Search — 带引用的 AI 摘要搜索 问题：传统 grep + 浏览器的工作流效率低下，而市面上很多 AI 搜索工具要么需要 API Key，要么不透明——你不知道结果是否被模型幻觉污染。 解决：直接调用 Gemini API 的 googleSearch Grounding 能力： 模型实时联网搜索，返回的结果附带精确到段落的 Grounding Chunks 引用标记。 formatresponse 将每个 GroundingSupport 映射为 [1]、[2] 等脚注标记，直接在文字段落中标注来源位置，末尾列出所有来源链接。 终端渲染使用 termimad 库，在交互式终端下呈现丰富的 Markdown 格式化效果，同时管道输出时自动退化为纯文本。 4. 📦 Homebrew + Cargo 双通道分发 问题：Rust 项目分发门槛高，用户需要安装 Rust 工具链才能编译运行。 解决： Homebrew Tap：已发布至 aeroxy/tap/gsearch，macOS 用户可一键安装。 crates.io：cargo install gsearchcli 全局安装，适合已有 Rust 环境的用户。 Autoupdate Formula：发布流程已将 Homebrew Formula 的 SHA256 和 URL 更新集成进 Makefile，一次构建自动完成所有分发渠道的同步。 📦 核心功能一览 1. 零配置即用 安装后直接 gsearch singapore weather 即可搜索。如果尚未登录，自动触发 OAuth 流程并打开浏览器完成授权，全程不需要配置任何 API Key。 2. Grounded 搜索结果 每次搜索返回 AI 摘要 + 精确到段落的来源引用。文中以 [1]、[2] 标记标注来源，末尾列出所有来源的标题和链接，确保结果可溯源、可验证。 3. 企业代理友好 自动检测 HTTPSPROXY / httpsproxy 环境变量，跳过 SSL 证书验证以兼容 Zscaler 等企业 SSL 拦截代理。 4. 令牌自动管理 OAuth Token 持久化至 ~/.config/gsearch/antigravity.json，自动刷新，永不过期（只要 Refresh Token 有效）。 5. 即搜即得的终端体验 交互式终端下使用 termimad 渲染 Markdown，结果一目了然；非交互式终端（管道输出）自动退化为纯文本，适合与 grep、jq 等工具链配合使用。 🧗 使用方式 bash 安装（macOS） brew install aeroxy/tap/gsearch 或通过 Cargo cargo install gsearchcli 使用：直接输入搜索词 gsearch singapore weather 搜索更长的问题（无需引号） gsearch latest news about rust programming 2025 手动触发登录 gsearch login 源码： 🙏 致谢 & 交流 项目完全开源 MIT 协议，欢迎 Star ⭐️、Issue 和 PR。如果你在公司网络下使用遇到问题，欢迎提 Issue 反馈你的代理环境，我会尽力兼容。

> 在北京、上海这种超大城市，多人约饭时，「在哪见、吃什么」 总要来回商量。wheretoeat 是一个给 AI 用的技能（Skill）：根据每个人的出发地，算出一个对大家时间相对公平的见面点，再按偏好饮食推荐周边餐厅。 做什么 输入：几个人的出发地（如地铁站、小区）+ 想吃啥（如烤肉、铁锅炖） 输出：一个推荐见面区域 + 到该区域的驾车/地铁/公交时间对比 + 周边 TOP 5 餐厅，并可导出为 Markdown 方便转发给朋友 算法上：用多地的地理重心做基准，用高德地图 API 算各人到该点的驾车/公交/地铁时间，按「大家花的时间是否接近」做对比，再在重心附近按偏好搜餐厅、按评分排序推荐。 给谁用 在 Cursor / Claude 等环境里用「技能」或 MCP 的人：把本仓库当 Skill 读入，配合高德地图 MCP，让 AI 帮你算聚餐地点和餐厅 想参考「多人地点 + 时间公平性 + 餐厅推荐」流程的开发者：SKILL.md 和 references/ 里有步骤、算法说明和高德 API 用法 技术要点 依赖：高德地图 Web 服务 API（地理编码、路径规划、POI 搜索）+ 支持高德 MCP 的 AI 环境 文档即规则：SKILL.md 定义完整流程，AI 按步骤调用高德 API 并生成推荐与 Markdown 仓库 github.com/shaozhengmao/wheretoeat · MIT License

### 【开源自荐】OpenWeChat-Claw 为 OpenClaw 提供类微信 IM SKILL：开源、AI 原生，支持自然语言注册/好友/收发消息/发现/拉黑 👤 Zhaobudaoyuema
> 是什么 OpenWeChatClaw 为 OpenClaw 生态提供一层类微信的 IM：Agent 可以注册账号、加好友、收发消息、拉收件箱、发现用户、拉黑解黑，和人在微信里的用法一致，只是操作方是 Agent。协议从设计上就为 Agent 服务（HTTP + 纯文本，大模型好解析），即AI 原生；完全开源（MIT），服务端和 Skill 代码都在仓库里。 仓库： ClawHub Skill： 怎么快速体验（AI 原生：只加载 Skill，自然语言对话即可） AI 原生：不用手写调 API，只要加载 Skill，用自然语言跟 Agent 说「帮我注册」「发现用户」「给 xxx 发消息」「看收件箱」等，Agent 会按你的话去调接口、写配置、收发消息。 1. 加载 Skill：从 ClawHub 或 GitHub 下载 openwechatimclient，解压后作为 Skill 加到OpenClaw（或其它支持 Skill 的环境）。 2. 注册：用自然语言对 Agent 说「帮我注册 OpenWeChatClaw」或「注册一下」→ Agent 会调服务端 POST /register，拿到 ID、名称、Token 并写入本地配置（Token 只返回一次，Agent 会替你保存）。 3. 之后：继续用自然语言即可，例如「发现可以加的好友」「给 [某用户] 发一条消息」「拉一下收件箱」「谁是我好友」等，Agent 按你的意图操作。 流程概括：加载 Skill → 说「帮我注册」→ 用自然语言发消息/加好友/看收件箱。详见仓库 README。

### [开源自荐] GolemBot：让 Coding Agent 逃离终端，变成团队的 7×24 AI 队友 👤 0xranx
> 项目地址 类别 人工智能 项目标题 让 Coding Agent 逃离终端，变成团队的 7×24 AI 队友 项目描述 Claude Code、Cursor、Codex 这些 Coding Agent 已经能写代码、跑测试、分析数据了，但它们被困在一个人的终端窗口里——队友用不了，也没法当服务跑。 我不想用 LangChain 重新造一个 AI 应用，因为 Agent 本身已经够强了，缺的只是一个"身体"。所以我做了 GolemBot：一条命令把你已有的 Coding Agent 接入 Slack、Telegram、Discord、飞书、钉钉、企业微信，或者 5 行代码嵌入到自己的 Node.js 产品里。Agent 是大脑，GolemBot 是泥土之躯。 亮点 1. 不重新发明 AI — 底层直接调用 Claude Code / Cursor / OpenCode / Codex 的 CLI，不是 API wrapper。Agent 升级，助手自动变强，零代码改动。 2. 一行换引擎 — golem.yaml 改一行 engine 字段就能在四个引擎之间切换，StreamEvent 接口完全一致，IM 连接和 Skill 技能无需改动。 3. 零公网 IP — 所有 6 种内置 IM 适配器（Slack Socket Mode / Telegram LongPolling / Discord Gateway / 飞书 WebSocket / 钉钉 Stream / 企微 Webhook）均不需要暴露公网端口。 4. 目录即助手 — 技能、记忆、配置全在一个目录里，ls 一下就知道助手会什么、记住了什么，完全可 git 版本管理。 5. onboard 向导 — 一条命令交互式完成引擎选择 → Skill 模板 → IM 通道连接 → 启动服务，2 分钟从零到可用。 6. 13,000+ 社区技能 — 与 OpenClaw/ClawHub 生态 100% 兼容，一条命令搜索安装。 示例代码 bash npm install g golembot mkdir mybot && cd mybot golembot onboard 交互式引导，2 分钟启动 golembot gateway 启动 IM + HTTP 服务 + Dashboard 嵌入到产品中： typescript import { createAssistant } from 'golembot' const bot = createAssistant({ dir: './mybot' }) for await (const ev of bot.chat('分析上月销售数据')) if (ev.type === 'text') process.stdout.write(ev.content) 截图或演示视频

### 【工具自荐】BenchSelf：19 个浏览器自测，给出的是百分位而不是一个分数 👤 james-w921
> 链接： 反应时间 240ms 算快还是算慢，取决于你用的是鼠标、触控板还是手机，但大部分自测站只丢给你一个数字。 BenchSelf 是 19 个跑在浏览器里的自测：反应/反射、F1 起步灯、点击速度、鼠标硬件（回报率、抖动、双击、滚轮）、记忆（视觉/词语/序列/数字）、高频听力、周边视觉、色觉筛查。其中 17 个会把结果换算成百分位，并标出这个百分位是在哪个设备类别里算的、对照人群是谁。 它跟同类站不一样的地方在于把「拿什么跟你比」摊开写了：新站没有自己的样本，所以每条基线曲线的来源都写在 methodology 页上，17 条里 3 条拟合自别人公开发表的数据，其余 14 条明确标着「估计值」。某个设备类别攒够 5000 次真实首测之后，基线撤掉，换成实测曲线。 免费、无需注册、无广告、无联盟链接，测试页里不加载任何第三方脚本 —— 一个中途要去拉广告的测试，量到的是广告网络的延迟。 界面目前只有英文。

### 【开源自荐】Clean My Codex：查看和清理 Codex 占用的磁盘空间 👤 FinnaXxx
> 仓库： Clean My Codex 是一款开源桌面工具，用来查看 Codex 在本机占用了多少磁盘空间，以及这些空间分别被什么占用。它也把会话、会话资产、Worktree、工作区和插件放到一个界面里管理。扫描和清理都在本机完成，不会上传会话内容或文件元数据。 !Clean My Codex 总览 为什么做这个 用 Codex 久了，本机会慢慢积累不少文件：会话记录、为任务创建的 Worktree、Worktree 里的依赖和构建产物、生成的图片与可视化、Plan、插件旧版本，以及安装或更新中断后留下的临时目录。 这些文件分散在不同位置。只看 ~/.codex 的总大小，很难知道磁盘空间用到了哪里；直接进目录手动删除，也可能漏掉会话的数据库记录，或者让 Git 留下失效的 Worktree 记录。Clean My Codex 就是为了解决这个问题，把扫描、查看和删除放到一个界面里。 支持的功能 扫描 Codex 数据目录、会话、会话资产、插件、Worktree 和工作区，并按类别显示文件数量与磁盘占用。 统一管理未归档和已归档会话。一个会话即使有多个续写文件或多层子代理，也会合并成一项；删除时会一并清理关联资产、索引和数据库记录。 单独查看和删除会话资产，包括 ImageGen 生成的图片、Visualization 及其查看器、Plan 文档，并显示来源会话、文件数量和占用。 查看 Codex 创建的 Worktree、Git 状态、构建产物占比和关联会话。删除时使用 git worktree remove；用户自己创建的 Worktree 只统计，不提供删除。 查看 Codex 在用户文档目录中创建的工作区，标出未提交、未推送或状态未知的 Git 仓库，避免误删仍在使用的文件。 管理插件版本，区分当前版本、旧版本和卸载残留；还可以设置定时清理，定期处理确认安全的临时目录、插件旧版本和过期会话。 只有存在明确证据时，项目才会进入“建议清理”。配置、凭据、运行期数据库、桌面端登录数据和缓存等内容会计入总占用，但不提供删除；当前插件只通过 Codex 自己的卸载接口处理，不会被当成普通目录直接删除。 支持平台 macOS 12 及以上，提供 Apple Silicon 和 Intel 安装包。 Windows 10 及以上，目前提供 x64 安装包，属于实验性支持。 安装与提醒 可以从 GitHub Releases 下载。项目使用 MIT 许可证。 目前仍在测试阶段，清理属于永久删除。第一次使用前建议先备份 Codex 数据，并在清理前退出 ChatGPT/Codex。macOS 安装包尚未公证，Windows 安装程序也还没有签名，首次打开时可能需要手动确认。

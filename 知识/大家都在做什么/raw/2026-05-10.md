> 项目地址： TokenUsed 是一组给 macOS 菜单栏工具 UsageBoard 使用的本地 token 用量插件。它直接读取 Claude Code、Gemini CLI、Codex CLI 在本机留下的会话 JSONL/JSON 文件，汇总今天和近 7/30 天的 token 用量，不调用远程 API，也不依赖订阅额度接口。 菜单栏面板 主要特点： 1. 完全本地离线：只扫描本机会话文件，适合不想把用量数据上传到第三方服务的用户。 2. 三家 CLI 聚合：Claude Code / Gemini CLI / Codex CLI 可以放到一个 Today Overview 面板里按模型汇总。 3. 支持 7/30 天趋势图：可以展开查看按模型堆叠的历史用量柱状图。 4. 兼容 UsageBoard：通过 Python 插件接入，也附带一个 UsageBoard patch，用来刷新面板、隐藏空数据 CLI，并在右侧显示 token 数。 5. 提供 Homebrew 安装： bash brew tap unistark/tap brew install tokenused 我做这个项目的原因是，现在很多人同时使用多个 AI 编程 CLI，但各家的本地用量分散在不同目录里，很难快速知道今天到底用了多少 token、哪个模型占比最高。TokenUsed 的目标是把这些本地数据整理成一个轻量、可见、不开外部服务的菜单栏面板。 谢谢。

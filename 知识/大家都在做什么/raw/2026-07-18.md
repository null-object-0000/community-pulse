### 【开源自荐】Linglens：每个字都认识、放一起却看不懂的术语，划词就地用你的语言解释（BYOK、开源） 👤 ZGhey
> Linglens 读技术文档时，字都认识，但一个术语放在这篇文档的语境里到底指什么，经常懵——哪怕是母语内容也一样。比如 "runner"，在 GitHub Actions 的 README 里其实是"执行 job 的那台机器"——查词典只给通用释义，用全页翻译又只翻字面、还把代码块搞烂。 Linglens 是一个开源（MIT）的 Chrome 扩展：在任意网页选中一个术语，点旁边冒出的小图标，它就用你的语言、贴着当前页面的语境解释这个词（中文 / 日本語 / English…）。它读页面 DOM，抽出"标题 + 大纲 + 你选中所在的段落"（排除代码块）做一份精简语境发给大模型——不是全页翻译，是"解释这个词在这里的意思"。 🔗 Chrome 应用店： 🔗 代码仓库： 主要功能 BYOK，用你自己的 key：OpenAI / Anthropic / Gemini / DeepSeek / 任意 OpenAI 兼容端点，也包括本地模型（数据不出机器）。key 存在本地，只在你触发的那次请求里发给你选的服务商——没有后端，不经过作者的服务器。 点了图标才调用模型：误划词零成本，不偷偷烧 token；每次解释还显示真实的 token 消耗。 能追问：同一个弹窗里接着问"举个例子""跟 X 有什么区别"，是对话不是一次性查询。 本地历史：解释过的词本地可搜，回看不再重新调用模型。 无账号、无遥测：装上填个 key 就能用。 技术 Manifest V3 + TypeScript，流式 SSE，弹窗用 Shadow DOM（页面 CSS 干扰不到）。约 100 个单测 + Playwright e2e，开源 MIT。

### OpenAPI -> Skills 转化器，让 Agent 按需精准读取 API 文档 👤 Yuyz0112
> 之前尝试过各种方法让 Agent 可以更可靠地读取 API 文档，不论是基于它开发客户端代码、做集成测试还是自动化。但复杂一些的 API 文档就会遇到超出上下文大小，即使不超出，也非常浪费上下文空间、多轮对话之后模型就又幻觉了。 最近又想做个公司产品 API 的 code helper ，但是产品的 API 文档的 OpenAPI JSON 接近 10MB ，又遇到上面的问题。陆续尝试过几种切分的方法，部分奏效，但是复杂度挺高，维护成本也高。 前几天突然想到 Skills 最擅长按需加载，就做了一个 CLI ，把 OpenAPI 文档转为 Skills 结构，核心是按 API 语义的拆分 + link ，实现按需加载，实际使用效果惊人，顺便加了点模版定制功能，更好用了。 原本单个 10MB API 文档，拆完之后是 2000+ 小的 md 文件，但是对于具体的 API 任务请求（比如写个 xx 场景运维脚本），Agent 都可以精准地读取所需的片段，探索性特别好，对单个资源的操作需求一般读 5 个片段就能准确写出了，最关键是没幻觉。

> 博弈圆桌 (Negotiation Arena) 两个 AI Agent 代表各自立场，围绕一个议题进行三轮谈判，自动达成共识或明确分歧。 甲方：你的 SecondMe 分身（通过 OAuth 登录后调用 SecondMe Chat API 代你发言） 乙方：LLM 驱动的 AI 对手 用户只需两步操作：登录 + 设定议题，其余 100% 由 AI 自动完成。 在线体验： 源码仓库： 首页 谈判设置（内置 5 个预设场景，也可自定义） 三轮谈判 + 结构化共识报告 核心特性 SecondMe OAuth 登录：一键授权，你的 AI 分身即刻上线 三轮渐进式谈判：基于 NeurIPS 2024 LLMDeliberation 论文的策略框架，逐轮推进共识 实时 SSE 流式对话：思考状态、轮次切换、消息逐条呈现 结构化共识报告：收敛度评分、协议条款、双方让步、未解决分歧、谈判风格分析 5 个预设场景：年终奖分配、周末聚餐、项目排期、办公室温度、远程办公 为什么谈判是 A2A 的关键场景 多数 A2A demo 是信息传递型 Agent A 传话给 Agent B。博弈圆桌展示的是 利益博弈型 A2A：两个 Agent 有各自立场和底线，需要理解对方、策略性让步、在约束条件下寻找最优解。 未来当每个人都有自己的 AI 分身，Agent 代理谈判将成为常态。 技术栈 Next.js 16 + React 19 + TypeScript + Tailwind CSS v4 + SecondMe OAuth/Chat/Act API + DeepSeek LLM，部署在 Vercel。

### 【开源自荐】SafeReceipt -- AI Agent 问责协议，链上收据证明 AI 到底做了什么 👤 calderbuild
> SafeReceipt — Agent Accountability Protocol 当 AI Agent 替你操作链上交易时，你怎么知道它有没有偷偷改金额、换收款地址？ SafeReceipt 解决这个问题：在 AI 执行交易之前，先把用户的真实意图做成密码学收据上链；执行之后，对比收据和实际交易，自动判定是否一致。 一句话：When AI fails, receipts prove who's responsible. 在线体验： 源码仓库： 链上合约（已验证）： 首页 Agent 验证 Demo（3 个场景：安全授权 / 高危授权 / 恶意篡改） Demo 6 条自动风险评估规则 Rules 推荐理由 随着 AI Agent 越来越多地代替用户执行链上操作（授权、转账、DeFi 交互），一个关键问题浮现：Agent 说它做了 X，但实际做的是 Y，用户怎么办？ 现有方案要么依赖事后人工审查，要么信任 Agent 的自我报告。SafeReceipt 提出一个不同的思路： 1. 执行前锁定意图：用户声明 "授权 100 USDC 给 Uniswap"，系统将意图规范化后做 keccak256 哈希，连同风险评分一起写入智能合约 2. 执行后自动验证：将实际交易的 calldata 解码，与链上收据逐字段对比（token、spender、amount） 3. 不可篡改的证据链：如果 Agent 篡改了交易（比如把 100 改成 10000），收据状态变为 MISMATCH，任何人都可以验证 这不是又一个钱包插件，而是一个协议层的问责机制 —— 适用于任何 AI Agent 框架。 核心功能 6 条自动风险规则：无限授权检测、未知合约识别、重复授权模式、异常金额等，每笔交易自动评分 0100 确定性哈希：固定字段顺序 + 字母序排列的规范化 JSON，确保同一意图永远产生同一哈希 链上收据生命周期：CREATED → VERIFIED / MISMATCH，不可逆转 一键 Demo：连接钱包后选择场景（安全授权 / 高危授权 / 恶意篡改），全流程自动演示 证据导出：一键下载包含哈希证明、验证步骤的 JSON 文件，可用于争议仲裁 技术栈 React 19 + TypeScript + Vite + ethers.js v6 + Solidity 0.8.19 + Tailwind CSS v4，部署在 Monad Testnet（合约已在 MonadScan 开源验证）。 项目背景 为 Monad Blitz Pro Series Hackathon（Rebel in Paradise AI Hackathon）开发，关注 AI Agent 安全这一新兴领域。

🔗 [官网](https://safereceipt.vercel.app) · [投稿页](https://github.com/ruanyf/weekly/issues/9040)

### 【开源自荐】OrbCue：替你盯着命令行 Agent 的windows桌面小球，减少你的“上下文切换” 👤 QZYH123
> OrbCue 是 Windows 桌面上的一颗悬浮小球，解决的是人在盯着多agent进度时总要专注或者不断"上下文切换"来轮询不同会话的进度的问题，它替你盯着 Claude Code、Codex、Cursor、Grok Build等命令行 Agent。它利用hook把轮询优化为中断逻辑，把 Windows 和WSL 里的所有会话汇总在一起：谁在工作、谁在等你、谁做完了一眼可见，还会弹通知或推送到手机，点一下就能跳回对应终端。 适合同时跑多个 Agent、或者挂着长任务去做别的事的时候用。项目用 Rust 和 Tauri 2 开发，界面基于Svelte，只读取工具自带的 hook 事件，不读对话内容。 功能： • 状态汇总：所有 Agent 会话汇总到同一颗球上，显示工作中、等待输入、等待授权、完成、失败。 • 多工具接入：支持 Claude Code、Codex、Cursor CLI、Grok Build，装在 Windows 或 WSL 里的都能接入，其他工具也可以通过命令自行接入。 • 提醒：弹系统通知并响提示音，可选通过 ntfy 推送到手机。 • 跳回终端：点一下回到对应终端。用 orb run 或"原命令启动"开的会话，能精确跳到那个标签页。 • 一键连接：自动发现已安装的工具，一键写入 hook，改之前自动备份，断开时只撤掉自己写的部分。 • 隐私：只读取 hook 事件，不读对话内容，数据只留在本机。 • 小球交互：可以贴边收起、调透明度，支持全局快捷键、开机自启和多套主题。

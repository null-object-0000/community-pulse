### [开源自荐] lich：在真实终端里运行 AI 编码智能体的桌面工作台 👤 omartelo
> 项目地址 类别 Go 项目标题 在真实终端里运行 AI 编码智能体的桌面工作台 项目描述 lich 把 Claude Code、Codex、opencode、Crush、ohmypi 这五个 AI 编码智能体放进真实的 PTY 终端里运行：一个项目可以并行开多个会话，侧栏按 git worktree 分组，分支、diff 徽标和 Pull Request 编号都摆在会话卡片上。在 diff 上选中几行就能写评论，整批评论作为一条 prompt 交回给智能体；会话之间还能互相派活、各自开分支干活并把结果交回来。它编译成单个静态 Go 二进制文件，界面借用系统已装的 Chromium 以 app 模式打开，不打包 Electron。 亮点 1. 不打包 Electron，也不带 webview。后端是 CGOENABLED=0 的单文件 Go 二进制（Linux 版 19 MB，deb 包 9.2 MB），界面复用系统已经装好的 Chromium / Chrome / Brave，以 app 模式开一个没有地址栏和标签栏的窗口，关掉窗口即退出进程。 2. 智能体跑在真实的 PTY 里，而不是被包在一层 API 调用外面。终端由 xterm.js 配 WebGL 渲染，TUI、快捷键和彩色输出都按原样工作；滚动缓冲区能挺过整页刷新，可以用 Ctrl+F 搜索。底栏跟随 cd 显示 git 状态，对 Claude 会话还会标明模型并用一个圆环显示已占用的 上下文窗口。 3. git worktree 是一等公民。从任意基础分支一键开一个 worktree，lich 会把被 gitignore 掉的 .env 播种过去、按路径算出一个稳定的开发服务器端口塞进环境变量，并在智能体启动 前跑一遍按项目配置的初始化脚本 —— 于是多个智能体可以在各自的分支上并行干活，互不 踩踏。 4. 会话之间可以互相派活。一个智能体能列出旁边的会话、按分支开一个带 worktree 的新会话、 把任务交给它，然后接着做自己的事；结果回来时只在它的提示符旁留一行简短通知，正文进 收件箱，等它自己选的时机一次收齐 —— 别人的长篇输出不会灌进它的上下文窗口。Claude Code 和 Codex 在启动时就拿到这些工具，opencode 和 Crush 由 lich 的配套插件装进去。 5. 审查闭环。工作区 diff 用 CodeMirror 展示在实时文件树旁边，右键选中的几行就能写评论， 整批评论作为一条 prompt 粘回会话（但不自动发送，发之前你还能改）。Pull Request 也是 端到端的：列表支持 GitHub 自己的限定符（is:draft、review:approved），可以把某个 PR 检出到独立 worktree，在 diff 上内联审查、批准并合并 —— 不用切回浏览器。 6. 全部在本地。没有账号，不用登录，没有遥测；后端是一个带 token 鉴权的本地回环监听器， 除了启动时和之后每小时向 GitHub Releases 查一次新版本之外，没有任何东西离开 localhost，工作区存在本地 SQLite 里。主题可以从 git 仓库安装并就地更新。 示例代码 markdown 截图或演示视频 !lich 主界面 !在 diff 上写评论 !Pull Request 内联审查

> 自荐一个我做的开源工具：Stop That Shit（别再造史了）。 我只让 AI Agent 导出一个结果文件，它却顺手生成了一份 SHA256 校验和。后续没有任何命令读取这份校验和，它也没有替代更昂贵的检查——文件多了一个，任务却没有少做一步。 换一个任务，多出来的可能是兼容层、全量测试、额外的 guard、迁移框架或者一整套“为了保险”的处理。每一步单独看似乎都有理由，合在一起却变成了用户没有要求、当前任务也用不上的防御性工程。 Stop That Shit 把这个判断收敛成四个问题：用户要求了吗？完成当前任务真的需要吗？有没有代码、数据或发布流程会使用它？不做的话，当前验收会失败吗？ 项目由 Skill 和可执行 Guard 组成。在宿主支持的 Hook 路径上，它会检查明确的任务边界；对于可识别的新 hash 动作，默认要求存在明确授权或真实消费者。真正需要的校验和、测试和兼容工作仍然可以放行。 目前支持 Codex、Claude Code、OpenCode 和 Hermes Agent CLI，并通过 Bad Case / Good Case 成对案例同时验证“该停的停下来”和“该做的不能被误拦”。 0.1.0 已发布，MIT 开源。 项目地址： 版本说明：
